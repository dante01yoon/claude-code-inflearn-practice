index.html 코드를 읽고 판단한다.

PASS if 아래를 모두 만족한다.
- 제목이나 머리글에 "달빛 카페"가 있다.
- 메뉴 다섯 개(아메리카노 4,500 / 카페라테 5,000 / 바닐라라테 5,500 / 레몬에이드 6,000 / 치즈케이크 6,500)가 가격과 함께 나온다.
- 메뉴마다 + / - 버튼이 있고, 누르면 수량과 합계 금액이 다시 계산되어 화면에 반영된다. 수량이 0 아래로 내려가지 않는다.
- 아이콘이나 기호(+, -)만 있는 버튼에 aria-label이 있다.
- "주문하기" 버튼을 누르면 주문 완료 메시지가 나온다.
- 장바구니 상태를 localStorage에 저장하고, 페이지를 열 때 다시 읽어 화면에 그린다.
- 좁은 화면(미디어 쿼리 등)에서 메뉴가 한 줄에 하나씩 놓이고, 합계와 주문하기 버튼이 화면 아래에 고정된다(position: fixed 또는 sticky).

FAIL if 위 항목 중 하나라도 빠졌거나, 코드상 동작하지 않을 것이 분명하다(정의되지 않은 함수 호출, 합계를 다시 계산하지 않음 등).
