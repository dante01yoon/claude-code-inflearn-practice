index.html 코드를 읽고 판단한다.

PASS if 아래를 모두 만족한다.
- 원래 내용(제목 "도서관 공지 (예시)", 공지 카드 두 개와 날짜, "여기" 링크)이 그대로 남아 있다.
- 원래 색(배경, 글자, 머리글 배경, 테두리, 카드 배경, 날짜 색, 링크 색)이 CSS 변수로 바뀌었고, 다크 상태에서 이 변수들이 어두운 배경·밝은 글자 값으로 다시 정의된다. 하드코딩된 흰 배경이 다크에서도 남아 있지 않다.
- 사용자가 따로 고르지 않았으면 prefers-color-scheme: dark 시스템 설정을 따른다.
- 토글 버튼이 있고, 기호·아이콘만 있으면 aria-label이 있다. 누르면 다크 ↔ 라이트가 바뀐다.
- 고른 테마를 localStorage에 저장하고, 페이지를 열 때 읽어 적용한다. 사용자가 고른 값이 시스템 설정보다 우선한다(예: 시스템이 다크여도 라이트를 고르면 라이트).

FAIL if 위 항목 중 하나라도 빠졌거나, 코드상 동작하지 않을 것이 분명하다(정의되지 않은 함수 호출, 저장만 하고 읽지 않음, 토글이 시스템 다크 설정을 이기지 못함 등).
