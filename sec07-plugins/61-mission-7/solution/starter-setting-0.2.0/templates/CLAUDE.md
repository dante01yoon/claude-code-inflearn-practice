# CLAUDE.md

## 대답

- 한국어로 답한다. 설명은 짧게, 바뀐 부분 위주로 한다.
- 큰 작업 전에는 폴더 구조와 데이터 모양부터 보고 계획을 짧게 말한다.
- 외부 라이브러리(deck.gl 등)를 쓸 때는 context7로 최신 문서를 먼저 확인한다.

## 웹 페이지

- 따로 말이 없으면 `index.html` 한 파일(CSS·JS 포함)로 만든다.
- 모바일 대응은 기본이다. 375px 너비에서도 깨지지 않게 한다.
- 사용자가 입력한 데이터는 localStorage에 저장해 새로고침해도 남게 한다.
- 아이콘만 있는 버튼에는 `aria-label`을 단다.

## 데이터

- `data/` 폴더는 원본이므로 고치지 않는다. 가공한 결과는 다른 곳에 저장한다.
