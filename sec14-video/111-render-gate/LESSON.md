# 111 · 검수 게이트를 훅으로 — 렌더할 때마다 저절로 검사

매번 "격자로 보고 확인해"라고 말하던 검사를 훅으로 묶습니다. 훅은 정해진 순간에 저절로 실행되는 명령이에요. 렌더가 끝나면 훅이 영상을 검사하고, 기준에 못 미치면 문제와 고칠 방법을 클로드에게 돌려보내 고치게 합니다.

시작: 앞 수업의 `mograph` 폴더. 두 번째 프롬프트용 배경음악은 [start/dante-run/music](../start/dante-run/music/)을 `public/music`에 복사하세요(CC BY 3.0, 출처 표기 필요).

## 실제로 쓴 프롬프트
① 훅 만들기
```text
렌더가 끝날 때마다 영상을 자동으로 검사하는 훅을 이 프로젝트에 만들어줘. out/에 mp4가 새로 생기면 해상도·길이, 소리가 있으면 음량이 -14 LUFS ±1인지, 0.5초 넘게 까만 화면이 없는지 보고, 1초 간격 격자 이미지를 out/check/에 남겨. 기준에 못 미치면 클로드가 알고 고치게 해줘. 소리가 너무 작은 짧은 시험 영상을 하나 만들어서 훅이 정말 막는지도 확인하고, 어떻게 동작하는지 한국어로 설명해줘.
```
실제 실행 3분 33초. 만든 것 → [solution/.claude](solution/.claude/)
- `.claude/settings.json`: `PostToolUse`(matcher `Bash`, 터미널 명령 직후) + `Stop`(답변 끝내기 직전, 뒤에서 돌린 렌더를 놓치지 않게) 두 곳에 같은 스크립트.
- `.claude/hooks/check-video.py`: `out/`의 새·바뀐 mp4만 검사 → 해상도(1080×1920) · 길이 · 음량(-14 ±1 LUFS, 소리 있을 때) · 0.5초 넘는 까만 화면, `out/check/`에 1초 간격 격자와 측정값 JSON. 못 미치면 stderr에 문제를 쓰고 **exit 2** → 클로드 코드가 그 내용을 클로드에게 전달. 통과면 조용히 결과만(`additionalContext`). 같은 실패는 한 번만 알림.
- `.claude/hooks/video-check.json`: 기준값. 가로 영상이면 숫자만 바꾸기.
- 시험: 소리를 아주 작게 만든 4초 영상(-66.8 LUFS) → 훅이 막음 → 음량을 맞춰 다시 → -14.0 LUFS로 통과. 끝 1초가 까만 영상으로 까만 화면 검사도 확인.

② 실제로 써 보기 — 검사 얘기 없이
```text
public/music의 배경음악을 story 영상에 깔아서 out/story-bgm.mp4로 렌더해줘.
```
실제 실행 1분 11초. 배경음악을 넣고 렌더하자 훅이 막음(**-25.1 LUFS**, 피아노 곡이라 작음) → 클로드가 음량을 맞춰 다시 만들어 **-13.0 LUFS**로 통과. 클로드의 솔직한 보고: 음량은 렌더한 파일에만 맞췄고 소스에는 반영하지 않아 다시 렌더하면 또 작게 나옴 → 필요하면 "음량 보정을 소스에도 반영해줘"로 이어서.

팁: 매번 하던 확인은 훅으로 · 기준은 숫자로 · 훅을 만들면 일부러 틀린 영상으로 정말 막는지 시험.
