# 110 · 이야기 숏폼 — 고양이의 등불 축제

그림 몇 장으로 메신저 알림 · 말풍선 · 길 따라 걷기가 있는 이야기 숏폼을 만듭니다. 장면마다 기법 하나씩 맡기면 쉽습니다.

시작: 같은 `mograph` 폴더(`public/mooncat`에 [start/mooncat-assets](../start/mooncat-assets/)).

## 실제로 쓴 프롬프트
```text
public/mooncat 에셋으로 25초 세로(1080x1920) 이야기 숏폼을 만들어줘. 이야기는 등불가게 검은 고양이(003)가 친구 메시지를 받고 달 다리까지 가서 등불 축제를 여는 것. 메신저 말풍선(UI 목업), 타자기, 경로 따라가기, 선 그리기, 마스크 리빌을 써줘. 끝나면 out/story.mp4로 렌더하고, 1초 간격 격자로 보고 이상한 곳은 고쳐서 다시 렌더해(최대 2번).
```
실제 실행 5분 29초 → `out/story.mp4`(1080×1920, 25초). 클로드가 짠 장면표:

| 구간 | 장면 | 기법 |
|---|---|---|
| 0–3.7초 | 비 오는 등불 골목, 알림 배너에 고양이가 놀람 | 메신저 알림 목업 |
| 3.5–10초 | 반딧불 친구와 채팅, 답장이 한 글자씩 찍힘 | 말풍선 UI · 타자기 |
| 10–16초 | 달 다리를 향해 S자 길을 걸음 | 경로 따라가기 |
| 16–21초 | 반딧불이 줄을 그리며 등불 10개를 켬 | 선 그리기 |
| 21–25초 | 원형 마스크가 열리며 축제 광장 | 마스크 리빌 |

1초 격자를 보고 두 군데 고쳐 한 번 다시 렌더: 도착한 고양이가 "달 다리" 표시를 가림 → 위치 이동, 아래 자막 상자가 고양이를 덮음 → 고양이를 위로. 채팅 초반 위쪽이 비어 보이는 건 실제 메신저처럼 일부러 둔 것이라고 알려 줌. 갤러리에서 만든 색·경로 도구(`theme`, `path`)를 다시 씀.

팁: 이야기는 한 문장으로, 쓸 기법은 이름으로. 장면 나누기는 클로드에게 맡기고, 격자로 보고 고치게 하기.
