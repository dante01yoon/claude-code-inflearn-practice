# 104 · 자막 · 고유명사 교정

받아 적기 → 용어 목록과 문맥 보기 → 글로 모르면 그 시점 화면 보기 → 원래 말 → 고친 말 → 근거로 기록. 확실하지 않으면 바꾸지 않습니다.

시작: 이전 수업(러프컷)을 마친 `dante-run` 폴더(`out/cut.mp4`가 있는 상태).

## 실제로 쓴 프롬프트
```
out/cut.mp4에 한국어 자막을 만들어서 out/captions.srt로 저장하고, 자막을 화면 아래에 입힌 out/cut-sub.mp4도 만들어줘. glossary.txt에 이 영상에 나오는 고유명사가 있어. 잘못 들린 말은 고치되 확실하지 않으면 그대로 두고, 고친 건 out/fixes.md에 원래 말 → 고친 말 → 근거로 적어줘.
```
실제 실행 4분 7초. 자막 9개. 고친 말: 단태 → 단테(용어 목록), 역돌 → 벽돌(그 순간 화면에 벽돌), 클로드코드 → 클로드 코드(용어 목록 표기), 섭에서는 → 수업에서는(근거가 가장 약한 교정이라 "직접 들어 보고 판단해 달라"고 표시). 용어 목록을 받아쓰기에 미리 넣으면 결과가 끌려가 근거로 쓸 수 없어서 넣지 않음. 결과 [result/captions.srt](result/captions.srt) · [result/fixes.md](result/fixes.md).

📏 단테 강의 녹화 원본, 화면 글자로 확인한 잘못 들린 곳 9군데 · 2번씩: 그냥 자막 9/9 · 9/9, 용어 목록 + 기록 8/9 · 9/9(1곳은 확실하지 않아 그대로 둠). 차이는 근거 기록.
팁: 화면에 글자가 나오면 그 시점 화면 보고 고치기 · 용어 목록은 화면에 안 나오는 이름용 · 모르면 그대로, 고친 건 근거와 함께.
