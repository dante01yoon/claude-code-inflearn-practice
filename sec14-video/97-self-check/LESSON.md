# 97강 · 렌더하면 스스로 보는 검수

콘택트 시트 = 영상을 1초마다 한 장씩 잘라 격자 한 장에 늘어놓은 그림. 클로드는 영상을 재생하지 못해도 그림은 볼 수 있다.

## 실제로 쓴 프롬프트 (95강 cat-video, `out/first.mp4` 대상)
```
out/first.mp4를 1초 간격 프레임 격자(콘택트 시트)로 만들어서 직접 보고, 글자 잘림·겹침·흐릿하게 겹친 장면 같은 결함이 있으면 고쳐서 out/first-v2.mp4로 다시 렌더해줘. 고친 뒤에도 격자로 다시 확인하고, 최대 2번까지.
```
실제 실행 2분 25초. 찾은 결함: 장면 전환(약 3.2–3.7초, 6.3–6.8초) 크로스페이드로 고양이가 반투명하게 겹침, 7초쯤 반딧불이 고양이 얼굴을 가림 → 전환을 `slide()`로, 반딧불을 고양이 뒤 레이어로. 다시 확인할 때 전환 구간 프레임을 따로 뽑음. 결과 `out/first-v2.mp4`.

📏 같은 데이터 영상 요청 3번씩(가리고 60점): 공식 스킬 47.0 → 스킬 + 자체 검수 48.7(최고 52), 시간 +39초, 비용 거의 같음.
