# 103강 · 러프컷 자동화

러프컷 = 실패한 부분과 "음", "어" 같은 추임새를 빼고 쓸 부분만 이어 붙이기. 클로드는 소리를 단어 시각까지 받아 적고 → 뺄 곳을 정해 구간 목록을 만들고 → 이어 붙이고 → 결과를 다시 받아 적어 빠진 말이 없는지 확인합니다.

시작: `start/dante-run`을 작업 폴더에 두고 그 안에서 `claude`.

## 실제로 쓴 프롬프트
```
raw.mp4는 단테가 장애물을 뛰어넘는 걸 찍은 원본이야. 부딪혀서 다시 한 실패 부분은 통째로 빼고, "음", "어" 같은 추임새도 잘라서 out/cut.mp4로 만들어줘. 말이 없어도 달리고 점프하는 장면은 남겨. 자른 구간은 out/cuts.json에 시작·끝·이유로 적어줘.
```
실제 실행 4분 44초. 78.2초 → 41.5초. 자른 곳 2개: 14.20–50.15초(실패한 첫 시도 전체), 61.66–62.42초(추임새 "어"). 기록 [result/cuts.json](result/cuts.json).
클로드가 따로 알려 준 점: 첫 시도를 빼면서 "이 배경은 컴피 클라우드로 만든 클레이 그림이에요"도 같이 빠짐 · 맨 앞 대기 화면은 요청이 없어서 그대로 둠.

📏 단테 강의 녹화 원본(377.4초)으로 짧은 요청 / 규칙 + 목록 남기기 2번씩: 다시 받아 적은 글자 일치율 둘 다 0.98, 규칙 쪽만 자른 곳을 이유와 함께 남김, 비용 $0.99 → $2.10.
팁: 짧게 요청하되 남길 장면은 말하기 · 자른 목록을 파일로 남기게 하기.
