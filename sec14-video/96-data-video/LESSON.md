npx create-video --yes --blank seoul-video && cd seoul-video

## 실제로 쓴 프롬프트
① 만들기
```
public/seoul에 있는 서울 지하철 데이터로 15초 세로(1080x1920) 모션그래픽을 만들어줘. 주제는 서울역의 하루 — 하루 중 언제 가장 붐비는지. 화면 숫자는 데이터 그대로 쓰고, 끝나면 out/seoul.mp4로 렌더해줘.
```
② 대조
```
방금 영상에 나온 숫자를 전부 데이터 원본과 맞춰 보고, 화면 값 · 원본 값 · 맞는지를 표로 보여줘.
```
결과(실제 실행 4분 15초 + 1분 5초): `out/seoul.mp4`(1080×1920, 15초). 가장 붐비는 시간 18시 · 승차 273,665 + 하차 214,060 = 487,725명(한 달 합계, 서울역 1호선). 하차만 보면 08시 274,196명. 대조 표: 시간대 22개와 결론 숫자 전부 일치. 클로드는 카운트업(0부터 올라가는 숫자)을 일부러 쓰지 않음 — 중간값이 데이터에 없는 숫자이기 때문.

📏 같은 요청 12편 중 데이터와 다른 숫자 0편. HyperFrames 3편 중 2편은 카운트업 중간값이 멈춘 화면에 보인다는 지적.
