# 107 · 모션 그래픽 기법 15가지 — 세로 갤러리를 클로드에게 만들게 하기

앞의 촬영 기법 15가지가 카메라와 장면 전환이었다면, 이번엔 화면 위 글자·숫자·도형을 움직이는 기법입니다. 네 묶음으로 나눕니다.

| 묶음 | 기법 |
|---|---|
| 글자 | 키네틱 타이포 · 단어 하이라이트 자막 · 타자기 · 마스크 리빌 · 형광펜 강조 |
| 숫자와 데이터 | 숫자 카운트업 · 차트 성장 · 진행 바 |
| 움직이기 | 선 그리기 · 경로 따라가기 · 콜아웃(화살표·동그라미) |
| 화면 짜기 | 순차 등장 · 이름표 · 화면 분할 비교 · UI 목업(메신저 말풍선) |

시작: [start/](../start/)의 세 폴더를 작업 폴더에 두고, 그 작업 폴더에서 실행합니다. 이 프로젝트 `mograph`는 이 묶음의 네 수업(107~110)에서 같이 씁니다.

```bash
npx create-video --yes --blank mograph   # 처음이면 "Ok to proceed? (y)" → y
cd mograph
npx remotion skills add                  # Remotion 공식 스킬
cp -R ../mooncat-assets public/mooncat
cp -R ../seoul-data public/seoul
claude
```

## 실제로 쓴 프롬프트
```text
public/mooncat의 「달빛 고양이 야시장」 에셋으로 모션 그래픽 기법 갤러리 영상을 만들어줘. 세로 1080x1920, 30fps. 기법마다 105프레임(3.5초)짜리 예시를 차례로 이어 붙이고, 위쪽에 "01 키네틱 타이포 · Kinetic Typography"처럼 번호·한글 이름·영문 이름 이름표를 계속 띄워(글씨 48px 이상). 화면 글자는 한국어로, 위아래 250px는 앱 화면에 가리니 중요한 건 가운데에. 01 키네틱 타이포(단어마다 크기·위치가 바뀌며 문장이 움직임) 02 단어 하이라이트 자막(말하는 단어만 색으로 강조) 03 타자기(한 글자씩 찍히고 커서가 깜박임) 04 마스크 리빌(가림막이 걷히며 글자가 드러남) 05 선 그리기(선이 펜으로 그리듯 그려짐) 06 숫자 카운트업(0에서 목표 숫자까지 올라감) 07 차트 성장(막대가 자라고 선 그래프가 그려짐) 08 순차 등장(항목이 시간 차를 두고 하나씩 등장) 09 경로 따라가기(캐릭터가 곡선 길을 따라 이동) 10 이름표(아래쪽에 이름·설명 카드) 11 형광펜 강조(단어에 형광펜이 칠해짐) 12 콜아웃(화살표·동그라미로 한 곳을 가리킴) 13 진행 바(전체 중 어디쯤인지 막대로) 14 화면 분할 비교(위아래로 나란히 비교) 15 UI 목업(메신저 말풍선이 하나씩 뜸). 끝나면 out/gallery.mp4로 렌더해줘. 렌더 뒤 기법마다 가운데 프레임을 격자로 만들어 보고 기법이 눈에 보이는지 확인해서, 안 보이는 건 고쳐서 다시 렌더해(최대 2번).
```
실제 실행 7분 24초 → `out/gallery.mp4`(1080×1920, 30fps, 15개 × 3.5초 = 52.5초). 클로드 보고:
- 렌더한 영상에서 기법마다 가운데 프레임을 뽑아 5×3 격자로 확인, 위아래 250px 가림 영역도 같이 표시 → 15개 모두 기법이 보여서 다시 고친 것 없음.
- 첫 렌더가 키네틱 타이포에서 오류로 멈춤(`interpolate()`가 `calc()` 문자열을 보간하지 못함) → 숫자로 보간하게 고쳐 다시 렌더.
- 요청과 다르게 한 점: 이름표가 한 줄에 안 들어가서 두 줄(한글 60px / 영문 48px)로 나눔. 폰트는 macOS의 Apple SD Gothic Neo라 다른 OS에선 대체 폰트로 바뀔 수 있음.

팁: 기법 이름을 알면 요청이 짧아집니다 — "숫자는 카운트업으로, 핵심 단어는 형광펜으로, 목록은 순차 등장으로".

완성 코드: [solution/mograph](solution/mograph/) — 갤러리(`src/gallery`)와 다음 세 수업의 결과(`src/dante`, `src/data`, `src/story`)가 모두 들어 있습니다. `npm i` 뒤 위처럼 `public/`에 재료를 넣고 `npx remotion render Gallery out/gallery.mp4`.
