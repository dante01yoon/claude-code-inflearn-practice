# 달빛 고양이 야시장 브랜드 키트

밤의 등불 야시장에서 고양이들이 가게를 여는 이야기. 톤은 **따뜻하고 포근한 밤**이다. 보랏빛 어둠 위에 주황·금빛 등불이 번지고, 움직임은 부드럽게 미끄러져 들어와 살짝 튕기며 멈춘다.

기준 구현은 아래 파일이다. 새 장면을 만들 때 먼저 열어 보고 같은 부품을 재사용한다.

| 파일 | 용도 |
|---|---|
| `src/scenes/AlleyScene.tsx`, `PlazaScene.tsx`, `FestivalScene.tsx` | 완성 장면 3개(오프닝·가게·엔딩). 레이아웃과 타이밍의 기준 |
| `src/elements/LanternCat.tsx` | 주인공. 등불이 깜빡이는 빛까지 포함 |
| `src/elements/Caption.tsx` | 모든 화면 글자. Jua + 크림색 + 보라/등불 그림자 |
| `src/elements/Rain.tsx`, `Sparkles.tsx` | 분위기 입자(비, 금빛 반짝이) |
| `src/gallery/common.tsx` | `Bg`, `Prop`, `Character`, `HeroCat`, `catFace`, `Vignette`, `CLAMP`, 에셋 이름표 |
| `src/gallery/*.tsx` | 카메라·전환·모션 기법 15가지 예시 |
| `src/fonts.ts` | `juaFont` |

**그림자 공식**

- 어두운 면 위 글자: `textShadow: "0 4px 18px rgba(40,10,60,0.85), 0 0 40px rgba(255,170,80,0.45)"` (`Caption` 기본값)

- 그림자는 늘 보랏빛이다. `rgba(0,0,0,…)`는 액자처럼 강한 대비가 필요할 때만.

## 2. 글꼴

- **Jua 하나만** 쓴다. `import { juaFont } from "../fonts"` 후 `fontFamily: juaFont`. weight는 400뿐이다.
- 화면 글자는 되도록 `Caption`으로 넣는다. 색·그림자·`whiteSpace: "pre"`가 이미 맞춰져 있다.
- 줄바꿈은 `"달빛 고양이\n야시장"`처럼 `\n`으로 직접 끊는다. 자동 줄바꿈에 맡기지 않는다.
- 문구는 짧고 다정한 해요체 한국어: "어서 오세요!", "등불가게 문 열었어요", "오늘 밤도 불을 밝혀요". 한 덩어리 최대 2~3줄.
- 영어는 기법 이름표처럼 보조로만 붙인다(`푸시 인 · Push-in`).

## 4. 주인공 규칙

주인공은 **003 등불가게 검은 고양이**(`characters/003_lantern_shopkeeper.png`, 1024×1536)다. 검은 털, 호박색 눈, 보라 저고리에 분홍 띠, 화면에서 볼 때 오른쪽에 초승달 등불을 든다.

- **모든 장면에 나온다.** 전환의 양쪽 장면에도 둘 다 나온다.
- **화면에서 가장 큰 캐릭터다.** 이미지 높이 520~820px(1080 화면 기준). 보통 600~800. 조연은 주인공 높이의 90% 이하(같은 화면에서 손님 400~560, 반딧불 180~430).
- 움직이는 장면에서는 반드시 `LanternCat` 또는 `HeroCat`으로 넣는다. 맨 `Img`로 넣으면 등불 깜빡임 빛이 빠진다. 예외는 정지 사진 연출(KenBurns 액자 속)뿐.
- 위치는 `HeroCat`의 `cx`(몸 중심)·`feet`(발 y)로 잡는다. 발은 화면 아래쪽 `feet` 960~1060에 두고 발밑 그림자를 켠다.
- 얼굴 기준 연출(푸시 인, 아이리스)은 `catFace(size, cx, feet)`로 얼굴 좌표를 구해 `transformOrigin`·원 중심으로 쓴다.
- 한 화면에 주인공은 한 마리. 좌우 반전하지 않는다(등불은 항상 화면에서 볼 때 고양이 오른쪽).
- 비율은 1024:1536(`CAT_ASPECT`)을 지킨다. 늘이거나 찌그러뜨리는 건 착지 스쿼시(SpringEntrance)처럼 순간적인 탄성 표현일 때만.

**조연**

| `019_astronomer_customer` (1024×1536) | 천문학자 손님 | 가게 장면의 손님 |

## 5. 화면 배치

**규격**: 1920×1080, 30fps. 장면 하나 110프레임(약 3.7초).

**레이어 순서(뒤→앞)**
1. 배경 `backgrounds/*.png`(1536×1024). 장면에서는 2112×1408로 키워 `left: -96`, `top: -120~-230`에 놓고 줌 여유를 둔다. 갤러리식은 `<Bg name=… />`(cover).
2. Shade: 글자 쪽을 어둡게 하는 가로 그라데이션 `rgba(25,10,45, 0~0.15 → 0.55~0.6)`.
3. 분위기 입자: 비 오는 장면 `Rain` 120~140, 축제·마법 장면 `Sparkles` 40~45개 `#ffcf7a`.
4. 소품·조연.
5. 주인공.
6. 글자(`Caption`), 말풍선.
7. `Vignette` 0.35~0.55(움직임이 강할수록 0.8까지), 페이드 아웃 판.

**구도**
- 주인공과 글자를 **좌우로 나눈다.** 주인공이 왼쪽 1/3이면 타이틀은 오른쪽에 `right: 140~150`, `textAlign: "right"`. 주인공이 오른쪽이면 왼쪽에 소품·손님을 둔다.
- 말풍선은 주인공 머리 위(`top` 100~250), `padding: "26px 44px"`, `borderRadius: 48`, `transformOrigin`은 고양이 쪽 꼬리 방향.
- 글자는 고양이 얼굴, 등불, 화면 중앙의 밝은 등불 무리 위에 얹지 않는다.
- 음식(061~064, 140~230px)은 탁자·의자(181~186, 330~480px) 위에 올려 놓는다. 발바닥 동전 261, 달 보석 262는 보상·마법 아이콘으로 공중에 띄운다.
- 가장자리 여백: 글자 오른쪽 140px 이상, 이름표 같은 고정 UI는 왼쪽 위 `left: 40, top: 36`.

**배경 고르기**

|---|---|---|
| `plaza` | 241-lantern-station-plaza | 가게·손님맞이 |

| `alley` | 246-rainy-lantern-alley | 오프닝, 비, 촉촉한 반사 |

## 6. 움직임 규칙

**시간**
- 프레임 수는 `n * fps`로 초 단위 표기한다(`interpolate(frame, [0.8 * fps, 1.6 * fps], …)`).
- 모든 `interpolate`에 clamp를 건다(`CLAMP` 또는 `extrapolateLeft/Right: "clamp"`).
- 장면 사이 전환: `slide({ direction: "from-right" })` + `linearTiming(0.5 * fps)`. 마지막 장면은 3.0~3.65초에 `#0d0618`로 암전.

**이징**

| 상황 | 이징 |
|---|---|
| 캐릭터·소품이 화면 밖에서 미끄러져 들어옴 | `Easing.bezier(0.22, 1, 0.36, 1)` |
| 글자 떠오름, 동전 날아감 | `Easing.bezier(0.16, 1, 0.3, 1)` |
| 카메라 이동(푸시 인, 팬) | `Easing.inOut(Easing.cubic)` |
| 통통 튀는 팝(소품, 말풍선) | `Easing.spring({ damping: 12~14 })` + `output: "perceptual-scale"` |
| 차분한 크기 변화(주인공 등장) | `Easing.spring({ damping: 200 })` + `output: "perceptual-scale"` |
| 퇴장·닫힘 | `Easing.in(Easing.cubic)` |
| 등장 오버슈트 | `Easing.out(Easing.back(1.8~2))` |

**정해진 동작**
- 배경은 장면 내내 천천히 줌: 1 → 1.08~1.1(또는 1.08 → 1). 배경이 완전히 멈춰 있는 장면은 없다.
- 주인공 등장: 화면 밖 -900px에서 2.2초 동안 미끄러져 오며 걷는 듯 통통 뛰고(높이 20px에서 0으로 줄어듦), 또는 0.92 → 1 스프링으로 커진다.
- 조연 등장: -700px에서 1.3초.
- 글자: 주인공보다 0.8~1초 늦게. 0.8초 페이드 + 40px 아래에서 떠오름. 부제는 타이틀보다 0.6초 뒤 페이드만.
- 말풍선: 0.7~1.1초에 스프링 팝(0 → 1). 주인공은 그 순간 40px 한 번 폴짝.
- 소품 팝: 0.3초(약 8프레임) 간격으로 차례로. 동전은 위로 240~300px 날아가며 ±20deg 돌고 사라진다.
- 계속 도는 잔움직임은 `Math.sin(frame / fps * k)`로: 반딧불 위아래 ±22px·기울기 ±6deg, 달 보석 ±10px·±8deg, 등불 깜빡임(`LanternCat` 내장). 진폭을 이보다 키우지 않는다.
- 대사는 다 나온 뒤 최소 2초 그대로 둔다(리딩 홀드).
- 박자 연출은 15프레임(120BPM) 단위.
- 입자·무작위 값은 `random("seed-i")`로 결정론적으로.

## 7. 하지 말 것

- Jua 외 글꼴, 굵기 변경, 시스템 기본 글꼴.
- 바탕을 순흑 `#000`·순백 `#fff`로 채우기, 밝은 면 위 검정 글자(진한 보라 `#3b2552` 사용). 아이리스 원 바깥만 예외.
- 차가운 파랑·청록·형광색 강조, 낮 장면 톤, 회색 무채색 그림자.
- 주인공이 빠진 장면, 주인공보다 큰 조연, 한 화면에 주인공 여러 마리, 좌우 반전, 등불이 잘리게 크롭, 다른 고양이를 주인공처럼 쓰기.
- 움직이는 장면에서 003을 맨 `Img`로 넣기(깜빡임 빛 누락).
- 캐릭터·소품 비율 늘이기, 배경을 1536×1024보다 좁게 남겨 가장자리가 보이게 하기.
- 그늘(Shade) 없이 밝은 배경 위에 크림 글자 얹기, 글자로 고양이 얼굴 가리기.
- 화면 흔들기, 번쩍임, 0.5초보다 짧은 연속 컷, 휩 팬 말고는 직선(linear) 이동.
- clamp 없는 `interpolate`, `Math.random()`, CSS transition·keyframes, `useCurrentFrame` 대신 setTimeout 같은 실시간 타이머.
- 긴 문장, 반말·딱딱한 문어체, 영어만 있는 문구.
- `public/mooncat`의 원본 PNG 수정. 새 에셋은 같은 폴더 구조와 번호 규칙(`NNN_snake_name.png`)으로 추가하고 `common.tsx`의 이름표에 등록한다.

## 새 장면 체크리스트

1. 바탕 `#1a0f2e`, 배경 이미지 + 느린 줌.
2. 주인공 `LanternCat`/`HeroCat`, 가장 크게, 발은 화면 아래쪽.
3. 글자는 주인공 반대편, `Caption`, 표의 크기, Shade로 받쳐 줌.
4. 이징은 표에서 고르고 모두 clamp.
5. 분위기 입자 하나(비 또는 반짝이)와 비네트.
6. 110프레임 안팎, 장면 사이 0.5초 슬라이드, 마지막은 `#0d0618` 암전.
7. Remotion Studio에서 각 장면 0초·1초·2초·끝 프레임을 확인한다.
