# 106 · 엔딩 장면 이어 붙이기

재료: `start/dante-run/scene/ending.mp4`(단테가 결승 깃발 앞에서 손을 흔드는 5초 · 1920×1080 · 30fps). 따로 만들 필요 없이 이 파일을 씁니다.

이어 붙일 때 챙길 세 가지: 규격(크기 · 프레임 수) 맞추기 · 배경음악은 엔딩 끝까지 · 길이가 바뀌면 음량 다시 재기.

시작: 이전 수업(배경음악 · 음량)을 마친 `dante-run` 폴더(`out/final.mp4`가 있는 상태).

## 실제로 쓴 프롬프트
```
scene 폴더에 엔딩 장면 재료가 있어. scene/ending.mp4를 out/final.mp4 뒤에 이어 붙여서 out/final-ending.mp4로 만들어줘. 배경음악은 엔딩 끝까지 이어지다가 서서히 작아지게 하고, 전체 음량은 -14 LUFS 그대로 맞춰줘.
```
실제 실행 1분 48초. 결과 38.2초(33.2 + 5) · -14.0 LUFS / -1.2 dBTP. 화면은 인코딩 설정이 같아 다시 인코딩 없이 이어 붙이고 이음매 프레임 확인. `final.mp4` 소리는 33초쯤 음악이 이미 꺼지도록 되어 있어 목소리와 음악을 재료부터 다시 섞음 → 엔딩이 시작된 뒤에도 같은 크기, 34.2초부터 4초 페이드아웃. 길이가 늘어 게인 3.1 → 3.3 dB. 들어 볼 곳: 원곡 37.5초쯤 새 음이 페이드 중에도 작게 들림(거슬리면 페이드를 더 길게). 기록 [result/loudness-ending.md](result/loudness-ending.md) · 결과 [result/final-ending.mp4](result/final-ending.mp4).

📏 같은 도구(ffmpeg ebur128)로 다시 잼: 38.2초 · -14.0 LUFS / -1.2 dBTP, 기록과 같음.
팁: 규격 먼저 · 음악은 완성본이 아니라 재료에서 다시 섞기 · 붙인 뒤 다시 재고 직접 들어 보기.
