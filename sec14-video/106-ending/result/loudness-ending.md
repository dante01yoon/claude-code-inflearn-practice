# 음량 측정 기록 — out/final-ending.mp4

`out/final.mp4` 뒤에 `scene/ending.mp4`(5초)를 이어 붙인 버전입니다.
측정 도구와 목표는 `loudness.md`와 같습니다(ffmpeg `ebur128`, `peak=true`, -14 LUFS / True Peak -1 dBTP 근처).

## 최종 결과 (out/final-ending.mp4)

| 항목 | 값 |
|---|---|
| Integrated loudness | **-14.0 LUFS** |
| True Peak | -1.2 dBTP |
| Loudness Range (LRA) | 18.9 LU |
| 오디오 | AAC 192 kbps, 48 kHz, 스테레오 |
| 길이 | 38.2초 (영상 33.2초 + 엔딩 5.0초, 1146프레임) |

## 처리 과정

1. 영상: `final.mp4`와 `ending.mp4`의 H.264 설정(SPS/PPS)이 바이트 단위로 같아서, 다시 인코딩하지 않고 concat으로 이어 붙임.
2. 오디오는 `final.mp4`의 소리를 쓰지 않고 재료부터 다시 섞음(기존 소리는 33.22초에서 음악이 이미 페이드아웃되어 있기 때문).
   - 목소리: `out/cut-sub.mp4` 앞 33.2초, 모노 → 스테레오. 엔딩 5초 동안은 무음(엔딩 영상 소리도 무음, -91 dB).
   - 음악: 곡 앞 38.2초, **-14.1 dB 고정**(기존과 같음). 시작 0–3초 페이드인, **34.2–38.2초(4초) 페이드아웃**.
     엔딩이 시작되는 33.2초에도 음악은 같은 크기로 이어지다가 1초 뒤부터 서서히 작아져 영상 끝에서 0이 됨.
3. 두 소리를 섞음(normalize 없이): -16.4 LUFS, True Peak -0.4 dBTP.
4. **+3.3 dB** 올리고 4배 오버샘플링(192 kHz)한 리미터(-1.3 dB 상한)를 거쳐 -14.0 LUFS / -1.2 dBTP.
   (길이가 늘어 섞은 소리가 -16.2 → -16.4 LUFS로 조금 낮아져서 게인을 3.1 → 3.3 dB로 맞춤.)

## 엔딩 구간 음악 크기 (평균 음량)

| 구간 | 평균 |
|---|---|
| 30–33초 (본편 끝) | -33.2 dB |
| 33.2–34.2초 (엔딩 시작, 페이드 전) | -33.6 dB |
| 34.2–36초 | -36.1 dB |
| 36–37.5초 | -49.7 dB |
| 37.5–38.2초 | -44.5 dB |

37.5초 뒤가 조금 큰 것은 원곡 이 자리에 새 음이 들어오기 때문입니다(원곡 기준 36–37.5초 -27.5 dB, 37.5–38.2초 -16.2 dB).
페이드는 그대로 적용되어 마지막 0.3초 최대 음량은 -44.2 dB입니다.
