# 엔딩 장면 (out/ending.mp4)

단테가 결승 깃발에 도착해 카메라를 향해 손을 흔드는 5초 장면. final.mp4 뒤에 바로 이어 붙일 수 있도록 규격을 맞춤.

## 만든 과정

1. **참조 프레임**: raw.mp4의 70초 지점 프레임(1920×1080)을 뽑아 화풍·캐릭터 참조로 사용
2. **엔딩 그림**: 참조 프레임 + 프롬프트로 이미지 생성 → `out/ending_still.png` (1376×768)
   - 펠트 하늘, 크림색 구름, 초록 펠트 언덕, 갈색 클레이 땅, 빨강·흰색 체크무늬 결승 깃발, 금색 동전
   - 단테: 보라·갈색 드레드 머리, 선글라스, 검은 정장, 흰 셔츠, 검은 넥타이. 웃으며 한 손을 들고 있음
3. **영상화**: 위 그림을 시작 프레임으로 넣어 image-to-video 5초 생성 (1924×1076, 24fps, 오디오 없음)
4. **규격 맞춤 (ffmpeg)**: final.mp4와 같은 1920×1080, 30fps, yuv420p, H.264 + AAC 48kHz 스테레오(무음)로 변환하고 정확히 5.000초로 자름 → `out/ending.mp4`

## 확인한 점 / 참고

- 화풍(펠트·클레이 질감, 색감)과 캐릭터 외형은 raw.mp4와 잘 맞음
- 단테가 손을 흔들고, 중간(약 3.5초)에 한 번 살짝 뛰어오름. 깃발은 바람에 펄럭이고 동전은 제자리에서 회전함
- 프롬프트에 "static camera"를 넣었지만 카메라가 좌우로 약간 흔들리듯 움직임(배경·깃대 위치가 조금씩 이동). 원본도 횡스크롤이라 크게 어색하지 않지만, 완전히 고정된 화면이 필요하면 다시 생성해야 함
- 원본 땅은 흙 단면이 두껍게 보이지만 엔딩 그림은 벽돌 한 줄만 보임 (구도 차이)
- 오디오는 무음 트랙임. 배경음악(music/)이나 효과음은 붙이지 않았음
- 아직 final.mp4에 이어 붙이지는 않았음
