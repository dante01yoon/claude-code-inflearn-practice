# 섹션 9 · 72강 미션 9 — 평일 하루를 더해 토요일과 바꿔 보기

## 미션
6월 대여이력에서 평일 하루(예: 6월 10일 수요일)를 뽑아 재생용 JSON을 하나 더 만들고, `bike.html`에서 토요일 ↔ 수요일을 버튼으로 바꿔 볼 수 있게 하세요. 날짜를 바꿔도 시각은 그대로여서 같은 시각을 두 요일로 비교할 수 있어야 합니다. 원본 CSV와 생년·성별 같은 열은 저장소에 넣지 않고, 테스트 통과 후 커밋.

## 채점표
1. 평일 재생용 JSON이 있다 2. JSON에 개인 속성 열이 없다 3. 원본 CSV가 git에 없다 4. 날짜 버튼으로 바뀐다 5. 날짜를 바꿔도 같은 시각 6. 테스트 통과 · 커밋

## 정답 풀이 (입력한 것 그대로)
```text
평일도 보고 싶어. 6월 10일 수요일 하루도 뽑아서 bike.html에서 토요일이랑 날짜를 바꿔 볼 수 있게 해 줘. 원본 CSV는 저장소에 넣지 말고
커밋해 줘
```
→ 6분 19초(녹화 1회). 6월 10일 156,472건 추출(원본 CSV는 `.gitignore`), `scripts/build-bike-trips.mjs`가 날짜를 받게(`npm run build:bike -- 2026-06-10`), `bike-trips.mjs`에 `BIKE_DAYS`, 파이썬으로 따로 세어 대조, 테스트 기준값 오기·첫 로딩 실패 후 재생 버튼 꺼짐 버그를 스스로 수정, 주소 `?day=2026-06-10`. 테스트 108개. 헤드리스 크롬에서 08:30 이동 중 토요일 1,148대 vs 수요일 2,913대. 저장소에는 `data/bike/bike-trips-20260610.json`(약 3.3MB)만. 커밋 df28a42(영상 속 03dcb01).

결과 화면: `npm start` → http://127.0.0.1:8000/bike.html — 08:30 토요일 1,148대 ↔ 수요일 2,913대, 수요일 시간대 막대는 8시·18시 두 봉우리(18시 17,277건).

⚠️ 첫 녹화는 같은 포트로 다른 녹화를 돌리는 바람에 화면 연결이 끊겨 버리고(클로드 작업 없음) 다시 녹화했습니다.
