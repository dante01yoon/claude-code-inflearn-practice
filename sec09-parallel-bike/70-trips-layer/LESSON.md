# 섹션 9 · 70강 하루 수만 건의 이동을 빛의 궤적으로 재생 — deck.gl TripsLayer

## 오늘 할 것
6월 13일(토) 따릉이 이동 13만 4천여 건을 빛나는 꼬리로 하루 동안 재생합니다. 화면이 읽는 데이터를 개인 속성 없는 작은 JSON으로 바꾸고, 밤 지도·긴 꼬리·3D 기울이기로 꾸밉니다.

## 개념 — TripsLayer 네 가지 값
1. 경로 `getPath`: 빌린 대여소 → 반납 대여소(대여이력에 실제 경로가 없어 직선)
2. 타임스탬프 `getTimestamps`: 빌린 시각·반납 시각(그날 0시부터 초)
3. 지금 시각 `currentTime`: 재생·슬라이더가 바꾸는 값 하나
4. 꼬리 길이 `trailLength`: 지금보다 얼마 전까지 흐리게 남길지

경로·시각은 처음 한 번만 만들고, 재생 중에는 지금 시각만 바뀝니다.

## 실습 (입력한 것 그대로, 한 번에 이어서 녹화)
```text
bike.html이 지금은 원본 CSV를 읽잖아. 재생에 필요한 값만 담은 작은 JSON으로 바꿔 줘. 생년·성별 같은 건 빼고
```
→ 1분 35초. `data/bike/bike-trips-20260613.json`(약 2.9MB, `{day, source, total, skipped, from[], to[], start[], end[]}` — 좌표는 넣지 않고 대여소 좌표 JSON에서 붙임), `scripts/build-bike-trips.mjs`(CSV가 있을 때 다시 만들기), 생년·성별·이용자종류·자전거번호·이용시간 등 제외, 테스트 86개(CSV를 치워도 JSON 테스트 통과).
```text
궤적이 잘 안 보여. 밤 지도처럼 어둡게 하고, 꼬리는 빛나는 색으로 길게, 지도는 3D로 비스듬히 기울여 줘
커밋해 줘
```
→ 4분 35초. 검은 남색 그라데이션 바탕, 넓고 옅은 주황 번짐 + 가늘고 밝은 심 두 겹(TripsLayer 2개), 꼬리 15분 → 30분(`TRAIL_S = 1800`), pitch 50°·bearing −15°, 같은 대여소 반납 점은 하늘색. 375px·재생 성능은 확인 못 했다고 밝힘. 커밋 2개.

결과 화면: `npm start` 후 http://127.0.0.1:8000/bike.html — 3,600배 재생, 07:37 이동 중 829대, 18:00 이동 중 3,223대(녹화 화면 값).

⚠️ 영상의 실습 장면은 69강 끝 상태의 사본에서 처음부터 끝까지 한 번에 다시 녹화한 것입니다(첫 녹화는 녹화 프로그램 오류로 파일이 저장되지 않음). 공개 앱 저장소에는 첫 실행의 결과가 커밋되어 있어 세부 값이 조금 다릅니다: 872c8b8 재생용 JSON(2.9MB), 670414c 밤 지도·빛 꼬리(꼬리 40분, pitch 55°). 영상의 커밋 9b7fd8e·73385a4는 사본에만 있습니다.

핵심 코드(bike.html): 이동마다 `pathBuf`(출발·도착 좌표)·`timeBuf`(시작·끝 시각)를 한 번 채우고, `TripsLayer` 두 겹(번짐 `getWidth: 6` + 심 `1.4`)에 `trailLength`·`currentTime: time`을 넘깁니다.
