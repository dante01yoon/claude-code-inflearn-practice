# 섹션 1 · 미션 1 — 역 카드를 누르면 3D 화면이 그 역으로

섹션 1에서 배운 기능을 한 번에 써서 「서울 라이브 3D」에 기능 하나를 완성합니다.
시작: `start/`(지난 수업 결과) · 정답: `solution/` · 촬영: Claude Code v2.1.296, Opus 5.5 · medium, 2026-10-11

## 미션
역 카드를 누르면 그 역이 3D 화면 가운데로 오고 강조되게 만들기. 다섯 가지를 지킵니다.
1. 먼저 CLAUDE.md에 규칙 한 줄: **선택한 역은 주소 끝에 `#역이름`으로 남긴다**
2. 계획 모드에서 계획부터 받고 승인
3. 구현은 auto 모드로, 권한 규칙(`.env` 금지 · push 확인)은 그대로
4. `/code-review`로 검토받고 고칠 것 고치기
5. 브랜치에 커밋하고 main에 합치기

확인: 브라우저에서 카드를 눌러 3D가 옮겨 가는지, 주소 끝에 `#역이름`이 붙는지.

## 시작하기
```bash
cd start
cp .env.example .env
git init && git add -A && git commit -m "가장 한가한 때 계산과 테스트"
claude
```

## 정답 풀이에서 입력한 것 (그대로)
```text
CLAUDE.md에 규칙 하나 추가해 줘. 선택한 역은 주소 끝에 #역이름으로 남긴다
Shift+Tab → plan mode on
역 카드를 누르면 그 역이 3D 화면 가운데로 오고 강조되게 해 줘
  → 질문 2개(대상 카드 / 강조 방식)에 추천안 → Submit → 1. Yes, and use auto mode
/code-review                                   # 1분 3초, 9건 → 고칠 것 · 작은 개선 · 넘어가도 되는 것
고칠 게 있으면 고치고, 브랜치에 커밋해서 main에 합쳐 줘   # station-focus 브랜치, 커밋 2개, fast-forward
```
짧은 프롬프트만으로 충분해서 자세한 버전은 쓰지 않았습니다.

화면에서 본 것: HTML을 고칠 때 `Loaded .claude/rules/html.md`. 구현 뒤 헤드리스 브라우저로 `#서울역` 열기 · 카드 클릭 · 뒤로 가기 · `#없는역`을 직접 확인. 리뷰가 찾은 "선택한 카드에서 키보드 포커스 표시가 사라짐" 등을 고침.
결과 보기: `cd solution && python3 -m http.server 8000` → 카드 클릭 (주소 끝이 `#%EC%8B%9C%EC%B2%AD`(= #시청)처럼 인코딩되어 붙음)

## 채점표
| 항목 | 정답 풀이 |
|---|---|
| CLAUDE.md 규칙 | `## 규칙`에 한 줄 (+ encodeURIComponent 안내) |
| 계획 승인 | 질문 2개 → 계획서 → Yes, and use auto mode |
| 권한 규칙 유지 | `.claude/settings.json` 그대로 |
| /code-review | 9건 → 고칠 것·작은 개선·재생 버튼 aria-label 수정 (넘어가도 되는 2건은 그대로) |
| 브랜치 → main | `station-focus`에 커밋 2개 → main fast-forward |

결과가 영상과 조금 달라도 다섯 가지를 지키고 화면에서 동작하면 성공입니다.

## 도전 과제 (정답 없음)
- 키보드 ← → 로 이전 역 · 다음 역으로 옮겨 가게 만들기
- 선택한 역의 아래쪽 그래프 카드도 함께 강조하기
- 작업을 마친 뒤 `/context`로 책상이 얼마나 찼는지 보고, 다음 작업 전에 `/clear`로 비우기

도전 과제도 짧은 부탁으로 시작하고, 결과가 빗나갈 때만 자세히 적어 보세요.
