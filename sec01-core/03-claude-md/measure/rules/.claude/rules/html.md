# HTML 파일 규칙

- 모든 `<button>`에 `aria-label`을 단다. 아이콘이나 기호만 있는 버튼(예: `▶`)도 무슨 동작인지 한국어로 적는다(예: `aria-label="시간대 자동 재생"`). JS 템플릿 문자열로 만드는 버튼에도 똑같이 단다. 버튼 글자가 바뀌면(재생 ↔ 정지) `aria-label`도 같이 바꾼다.
- 화면 폭 375px에서도 레이아웃이 깨지지 않아야 한다. 가로 스크롤이 생기거나 글자·차트·컨트롤이 잘리거나 겹치면 안 된다.
  - 고정 폭(`width: 400px` 등)이나 375px보다 큰 `min-width`는 쓰지 않는다. 좁은 화면 스타일은 기존 `@media (max-width: 600px)` 블록에 넣는다.
  - 고친 뒤에는 375px 폭에서 3D 장면, 시간 슬라이더와 재생 버튼, 차트 카드, 표를 확인한다.
