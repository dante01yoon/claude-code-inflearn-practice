# 섹션 5 · 52강 미션 5 — 역 답 카드에 가까운 장소의 지금 혼잡도

## 미션
역 답 카드에 가까운 도시데이터 장소의 지금 혼잡도를 보여 주세요. 가깝다 = 역에서 장소 테두리까지 거리(역이 장소 안이면 0), 반경·개수는 직접 정하기, 값 없는 장소는 '값 없음', 테스트 먼저.

## 채점표
1. 테스트를 먼저 쓰고 실패를 봤다 2. 장소 안의 역은 거리 0 3. 값 없는 장소를 '값 없음'으로 4. 화면에서 직접 확인(힌트: 시청·광화문역은 sample 키로도 값이 보임) 5. 커밋

## 정답 풀이 (입력한 것 그대로)
```text
역 카드에 가까운 도시데이터 장소의 지금 혼잡도도 같이 보여 줘. 테스트 먼저 쓰고
커밋해 줘
```
→ `tests/nearby-places.test.mjs`(7개: 장소 안의 점, 가장 가까운 변·꼭짓점까지 거리, 구멍, 여러 조각, 반경·순서·3곳 제한, 실제 데이터) 먼저 → 실패 확인 → `nearby-places.mjs`(500m, 3곳) → 529역 중 163곳에 가까운 장소. 테스트 72개 통과. 헤드리스 브라우저로 시청역 확인(광화문·덕수궁 보통, 덕수궁길·정동길·시의회 앞 값 없음), 테스트가 못 잡은 초기 렌더 오류를 화면 확인으로 잡아 고침. 커밋 `9bdc9c6`. (이번 회차는 클로드가 영어로 답함)
