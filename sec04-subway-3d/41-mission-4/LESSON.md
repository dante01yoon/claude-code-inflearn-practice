# 섹션 4 · 41강 미션 4 — 지금 시간대 혼잡 TOP 5 + 검증 + PR

## 미션
1. 역 검색창 아래에 **지금 시간대 혼잡 TOP 5** 목록(슬라이더 시간대에서 승차+하차가 가장 많은 역 5곳)
2. 목록에서 역을 누르면 그 역이 선택(답 카드·지도까지)
3. Playwright로 직접 열어 확인하게 하기
4. 커밋 → 브랜치 push → GitHub PR

준비: 39강까지 마친 `seoul-live-3d`, `.mcp.json`에 Playwright MCP(38강). 막히면 `solution/`에서 이어서.

## 힌트
- 짧게 시작(데이터·계산·화면 틀은 이미 있음) · 화면 기능이니 검증 한마디(40강 결론) · `git push`는 권한 규칙(ask)으로 확인 질문이 뜸 → 명령을 보고 직접 허락

## 풀이에서 입력한 것 (그대로)
```text
검색창 아래에 지금 시간대 혼잡 TOP 5 목록 넣어 줘. 누르면 그 역이 골라지게. 다 만들면 playwright로 직접 열어서 확인하고 고쳐 줘
```
→ 약 2분 25초. 순위·역 이름·노선·하루 평균 인원, 누르면 검색 결과와 같은 방식으로 선택 + "선택 역 주변" 시점, 고른 역 노란 테두리, 버튼마다 aria-label(예: "2위 고속터미널 …, 11시대 하루 평균 10,149명, 고르기"), 재생 중 포커스 유지. Playwright로 표시·클릭·슬라이더/재생·375px 확인. **검증 중 발견한 버그**: 02·03시대에 한 달 몇 명뿐인 역이 반올림돼 "0명"으로 TOP 5에 오름 → 하루 평균 1명 미만은 빼고 안내 문구. 테스트 40개 통과.
```text
커밋하고 브랜치 push한 다음 main으로 PR 만들어 줘
```
(녹화 도구 문제로 이 장면은 `claude --continue`로 이어서 다시 입력: `커밋은 됐으니 브랜치 push하고 main으로 PR 만들어 줘`)
→ `git push`에서 "Ask rule Bash(git push *) overrides auto mode" 확인 질문 → Yes → PR https://github.com/dante01yoon/seoul-live-3d/pull/2 (섹션 4 커밋 11개 전체), 확인 후 main에 합침
```bash
gh pr view --json number,title,state,url | cat
```
