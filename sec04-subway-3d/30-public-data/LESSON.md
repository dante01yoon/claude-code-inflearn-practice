# 섹션 4 · 30강 공공데이터 고르기 — 파일 vs 오픈 API, 인증키 발급과 보관

서울 라이브 3D의 첫 레이어 「지하철 24시」에 쓸 재료를 고릅니다. 공공데이터가 무엇인지, 파일로 받을지 API로 부를지, 인증키를 어디에 둘지 정하고, 받은 데이터를 지도에 점으로 찍어 확인합니다.

## 개념
- 공공데이터 = 정부·지자체가 공개한 **재료 창고**. 서울시 데이터는 공공누리 제1유형(출처 표시하면 변경·상업 이용 가능).
- 파일 데이터 = **통조림**(한 달 치를 통째로, 키 없이), 오픈 API = **수돗물**(필요할 때 그때그때, 인증키 필요, 실시간은 API로만).
- 이번 앱: 한 달 승하차는 파일, 실시간 열차 위치는 API(37강).

인증키 신청: https://data.seoul.go.kr/together/mypage/actkeyMain.do (로그인 필요 — 강의에서는 발급 화면 안내까지만, 공개 `sample` 키 사용). 안내 문구: 실시간 지하철 오픈API는 하루 최대 1,000회, 1회 최대 1,000건.

## 입력한 것 (그대로)
```bash
claude
```
```text
서울 열린데이터광장 sample 키로 지하철 시간대별 승하차 API 불러 봐. 역이 전부 와?
```
→ sample 키는 앞쪽 5행만(`1/1000` 요청 시 `ERROR-335`, `6/10`도 막힘). 개인 키도 한 번에 1,000행까지라 나눠 받아야 함.

받은 CSV 두 개를 `data/raw/`에 넣고:
```bash
ls data/raw
claude
```
```text
data/raw에 받은 CSV 두 개가 각각 어떤 데이터인지 정리해 줘
```
```text
역사마스터 CSV로 역 위치만 지도에 점으로 찍어 보는 간단한 페이지 만들어 줘
```
```text
나중에 내 인증키를 받으면 어디에 둬야 안전해?
```

## 결과
- 두 파일 모두 CP949. 승하차↔역사마스터는 호선 표기(경의선/경의중앙선, `공항철도 1호선`/`공항철도1호선`, `9호선2~3단계`/`9호선(연장)`)와 역 이름(괄호 부역명 등) 11곳이 어긋남 → 34강.
- `stations.html`: Leaflet + OpenStreetMap, 역 655곳·노선별 784개 지점. 보기: `python3 -m http.server 8000` → http://127.0.0.1:8000/stations.html
- 인증키 보관: `.env`(`.gitignore`에 있음) + `.claude/settings.json`의 `Read(./.env)` 거부 규칙. 페이지 코드에 키를 넣으면 소스 보기로 누구나 봄 → 키는 스크립트·서버에서만.

## 인증키 보관 4단계
1. `.env`에만 `SEOUL_API_KEY=…` 2. `.gitignore` 확인 3. 클로드 읽기 거부 규칙 4. 화면·대화창·커밋에 붙여 넣지 않기
