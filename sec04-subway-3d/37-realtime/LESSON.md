# 섹션 4 · 37강 실시간 열차 위치를 노선 위에 — http API는 서버를 거쳐 부르기

## 개념
- 브라우저에서 바로 부르면 ① 인증키가 주소에 들어가 노출 ② API가 `http://swopenapi.seoul.go.kr`이라 https로 배포한 페이지에서는 혼합 콘텐츠로 차단
- 해결: 서버 경유(프록시) — 브라우저는 우리 서버 `/api/trains`만, 서버가 `.env` 키로 서울시 API를 부르고 열차 정보만 추려 돌려줌
- 실시간 API는 좌표 없이 "진입·도착·출발"만 → 34강 노선 순서 + 역 좌표로 위치 계산

## 입력한 것 (그대로) — 서버라는 말 없이 조건만
```text
실시간 열차 위치도 지도 노선 위에 띄워 줘. 인증키는 브라우저에 보이면 안 돼
```
→ 약 8분 40초. `server.mjs`(정적 파일 + `/api/trains`, 20초 캐시, 응답 항목 9개만, 오류 문구에서 키 가림, 점으로 시작하는 경로 404), `train-positions.mjs`(역 이름으로 매칭, 종착역 방향, 상·하행 옆으로 띄우기), 테스트 7개 추가(40개 통과). 클로드가 서버를 띄워 `.env`·`.git`·`../` 경로를 직접 요청해 보는 자체 공격 테스트. 실행은 `npm start`(python http.server는 `.env`까지 내보내므로 쓰지 않음).
- 공개 `sample` 키: 노선마다 5대(확인 때 93대). 실시간 지하철 인증키를 `.env`에 `SEOUL_REALTIME_KEY=…`로 넣으면 전체 열차
```text
커밋해 줘
```
→ `7dd9b76` 지하철 지도에 실시간 열차 위치 추가(인증키는 서버에서만)

## 남은 문제(클로드 보고)
- 일부 구간(경춘선 광운대·청량리, 서해선 김포공항–대곡 등)이 노선 순서에 없음 → 38강에서 일부 보완
- 실시간 API 하루 호출 한도 미확인(안내 페이지: 실시간 지하철 하루 최대 1,000회)
