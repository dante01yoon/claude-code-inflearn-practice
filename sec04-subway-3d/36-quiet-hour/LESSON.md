# 섹션 4 · 36강 내 역 고르면 시간대별 그래프와 "가장 한가한 시간" 추천

ROADMAP 3단계: 역 검색 → 답 카드(시간 창 안 가장 한가한 때 + 피크 대비 %) · 하루 띠 · 시간대 그래프, 지도 기둥을 눌러도 역 선택.

## 개념
- 답 카드 계산(PRD 4장): ① 시간 창(출근 06–09 · 낮 10–15 · 퇴근 16–19 · 저녁 20–23 · 직접) ② 창 안에서 승하차가 가장 적은 때(0명 시간 제외) ③ 그 역 피크 대비 %
- 계산은 `stats.mjs`의 `quietestInWindow`·`peakRatio`(33강) — 계산은 테스트로, 화면은 눈으로
- 예외 상태: 자정을 넘는 창, 동률, 기록 없음 / HTML 규칙: 버튼 aria-label, 375px

## 입력한 것 (그대로)
```bash
CLAUDE_CODE_ENABLE_TODO_TOOLS=1 claude
```

