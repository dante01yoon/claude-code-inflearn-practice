# 섹션 4 · 34강 데이터 수집·정제 — 역 이름 정규화, 노선 순서, 빈 값

ROADMAP 2단계: 9월 승하차 CSV 전체를 앱이 쓰는 모양으로 읽고, 역사마스터 좌표와 이어 붙이고, 노선별 역 순서를 정리하고, 지도로 확인합니다.

## 개념
- 정제 = 정규화(같은 것을 같다고 맞추기) · 빈 값 처리 · 검사
- 원본은 그대로 두고 읽을 때 코드에서 바꾼다(`data/CLAUDE.md` 규칙)
- 짐작 금지(매핑표에 적기) · 같은 이름 ≠ 같은 역 · 규칙마다 테스트

## 입력한 것 (그대로)
```bash
CLAUDE_CODE_ENABLE_TODO_TOOLS=1 claude
```
```text
ROADMAP 2단계 해 줘. 역 이름이 안 맞는 건 어떻게 맞췄는지도 알려 줘
```
→ `subway-csv.mjs`(CSV → API 행 모양 어댑터, 환승역 합산, 좌표 연결), 점검 스크립트·테스트 갱신. 약 4분 51초.
- 역명 528개 중 517개는 그대로 일치, 11곳은 `STATION_NAME_ALIASES` 매핑표
  - 부역명 차이: 낙성대(강감찬)·삼각지(전쟁기념관)·용마산(용마폭포공원)·마곡나루(서울식물원)·동대문역사문화공원(DDP) → 괄호 없는 이름, 숙대입구(서울시교육청) → 숙대입구(갈월), 상봉 → 상봉(시외버스터미널)
  - 원본 글자 깨짐: 하남시청(덕풍?신장) → 하남시청(덕풍-신장)
  - 이름이 바뀐 역: 자양(뚝섬한강공원) → 뚝섬유원지, 평택지제 → 지제, 한국항공대 → 화전 (좌표도 테스트로 확인)
- 노선 표기: 경의선 → 경의중앙선, 공항철도 1호선 → 공항철도1호선, 9호선2~3단계 → 9호선(연장)
- 같은 이름 다른 역: 5호선 양평(영등포구)과 중앙선 양평(양평군), 약 54km → 합치지 않음(역 529곳)
```text
노선마다 역 순서도 정리해 둬. 나중에 열차 위치 그릴 때 쓸 거야
```
→ `subway-lines.mjs`: 운행 계통 기준 24개 노선, 역은 "역사_ID 역사명"으로. 역사_ID 순서는 동묘앞 등이 엉뚱한 자리에 와서 직접 적고, 꺾임 검사(A→B→C가 A→C 직선의 1.8배 초과 시 실패)·거리 검사(이웃 역 11km 이내)·빠짐 검사로 확인. 상행·하행 방향은 열차 위치 API를 붙일 때 정하기로.
```text
stations.html을 9월 승하차 역이 다 제자리에 찍히는지 보는 지도로 바꿔 줘. 좌표 못 찾은 역은 빨갛게
```
→ 파랑 = 이름 그대로 일치, 주황 = 매핑표로 맞춘 16행, 빨강 = 못 찾은 역(실제 0곳, 복사본에서 일부러 좌표를 지워 빨간 표시 동작 확인)
