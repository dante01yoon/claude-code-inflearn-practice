# 섹션 0-1 · 12강 미션 0 — 폴더를 만들고 첫 웹 페이지 만들기

## 미션
1. 터미널에서 새 폴더를 만들고 들어간다.
2. `claude`를 실행하고 폴더를 믿는다고 답한다.
3. 내 취미(또는 좋아하는 것)를 소개하는 웹 페이지를 `index.html`로 만들어 달라고 짧게 부탁한다.
4. 브라우저로 열어 확인한다.
5. 바꾸고 싶은 점 하나를 말해서 고친다.

## 이번 수업에서 입력한 것 (정답 예시, 그대로)

```text
mkdir my-first-page
cd my-first-page
claude                       → Yes, I trust this folder
내 취미인 등산을 소개하는 웹 페이지를 index.html로 만들어 줘
색을 초록 계열로 바꾸고, 다녀온 산 세 곳(북한산, 설악산, 한라산)을 카드로 보여 줘
/exit
ls
```

정답 파일: `solution/` (첫 번째 결과 `solution/v1/index.html`, 고친 결과 `solution/index.html`).

보너스 과제: ① 내 사진 파일을 폴더에 넣고 페이지에 넣어 달라고 하기 ② 밝은/어두운 화면 바꾸는 버튼 ③ 다녀온 날짜·걸린 시간 표.
결과는 매번 조금씩 다릅니다. 페이지가 열리고, 내가 말한 내용이 들어 있으면 성공입니다.
