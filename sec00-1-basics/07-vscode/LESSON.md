# 섹션 0-1 · 7강 VS Code 설치와 내장 터미널에서 실행

## 이번 수업에서 입력한 것 (그대로)

```text
Ctrl + `                     # 내장 터미널 열기 (macOS·Windows 같음)
claude
index.html에 '안녕하세요' 한 줄이 보이는 웹 페이지를 만들어 줘
/desk                        # 자동 완성 목록에서 /desktop 확인만 (실행하지 않음)
/exit
```

## 핵심 정리 (공식 문서 확인)

| 항목 | 내용 | 근거 |
|---|---|---|
| VS Code 받기 | https://code.visualstudio.com 에서 내 운영체제용 설치 | VS Code 공식 사이트 |
| 내장 터미널 | `` Ctrl+` `` 로 열고 `claude` 실행. 클로드 코드가 편집기와 자동으로 연결되어 변경 내용 보기 등을 함께 씀 | [vs-code#run-cli-in-vs-code](https://code.claude.com/docs/en/vs-code) |
| VS Code 확장 | 그래픽 패널로 쓰는 공식 확장도 있음(VS Code 1.94 이상). 이 강의는 터미널(CLI)로 진행 | [vs-code](https://code.claude.com/docs/en/vs-code) |
| 데스크톱 앱으로 이어 가기 | 터미널에서 `/desktop` → 세션을 저장하고 데스크톱 앱에서 열기(macOS·x64 Windows, 구독 계정). 셸에서는 `claude --desktop` | [desktop#coming-from-the-cli](https://code.claude.com/docs/en/desktop) |

녹화 화면은 브라우저에서 띄운 VS Code(code-server, 같은 화면 구성)입니다.
