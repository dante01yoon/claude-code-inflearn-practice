# 섹션 0-1 · 10강 세션 이어 가기 — `--continue`, `--resume`, 새로 시작할 때

## 이번 수업에서 입력한 것 (그대로)

```text
claude
오늘 할 일 세 개를 todo.md 파일로 만들어 줘
/rename todo-list            # 세션에 이름 붙이기
/exit
claude --continue            # 이 폴더의 가장 최근 세션 이어서
방금 어떤 파일을 만들었지?
/exit
claude                       # 새로운 세션 (앞 대화를 모름)
방금 어떤 파일을 만들었지?
/exit
claude --resume              # 목록에서 골라 열기 → todo-list 선택
todo.md에 '물 2리터 마시기'를 하나 더 추가해 줘
/exit
```

## 핵심 정리 (공식 문서 확인)

| 명령 | 하는 일 | 근거 |
|---|---|---|
| `claude` | 새로운 세션 | [sessions](https://code.claude.com/docs/en/sessions) |
| `claude --continue` (`-c`) | 지금 폴더의 가장 최근 세션 다시 열기 | 같은 문서 |
| `claude --resume` (`-r`) | 세션 목록에서 골라 열기. `claude --resume 이름`은 바로 열기 | 같은 문서 |
| `/resume` | 세션 안에서 다른 세션으로 바꾸기 | 같은 문서 |
| `/rename 이름` · `claude -n 이름` | 세션 이름 붙이기 | 같은 문서 |
| `/clear` | 빈 대화로 새로 시작(이전 세션은 저장되어 `/resume`으로 돌아갈 수 있음) | 같은 문서 |

- 세션은 **폴더마다** 따로 저장됩니다. 같은 폴더에서 열어야 이어집니다(목록에서 `Ctrl+A`를 누르면 모든 프로젝트).
- 전혀 다른 일을 시작할 때는 새로운 세션이 좋습니다. 앞 대화가 길게 남아 있으면 요청마다 그만큼 더 읽습니다.

## 녹화에서 나온 결과
- 할 일 내용을 말하지 않아서 `todo.md`는 "할 일 1~3" 빈 자리로 만들어졌고, 클로드가 무엇을 넣을지 되물었습니다.
- `--continue`로 연 세션은 "todo.md를 만들었다"고 정확히 답했고, 새로운 세션은 "이번 세션에서는 아직 만든 파일이 없다"고 답했습니다.
- `--resume` 목록: 방금 연 세션 → `todo-list` → (폴더를 믿기 위해 잠깐 켰던 세션) 순서.
- 결과 파일: `solution/todo.md`

## 연습 과제 정답

```text
claude -n 내-첫-세션
안녕, 오늘 날짜를 알려 줘
/exit
claude --resume 내-첫-세션     # 목록 없이 바로 그 세션이 열림
```
