# 섹션 0-1 · 9강 첫 부탁 해 보기 — 원하는 것을 말하는 법, 결과 확인

## 짧은 프롬프트 (먼저 이렇게 시도)

```text
카페 메뉴 페이지 만들어 줘
```

결과: 그럴듯한 카페 메뉴 페이지가 나오지만, 가게 이름·메뉴·가격은 클로드가 지어낸 것입니다. 내가 원하는 가게 정보는 말하지 않았으니 알 수 없죠.

## 자세한 프롬프트 (빗나갔을 때 다시)

```text
index.html을 아래 내용대로 다시 만들어 줘.
- 가게 이름: 단테 커피
- 메뉴와 가격: 아메리카노 4,000원, 카페라테 4,500원, 바닐라라테 5,000원, 콜드브루 4,800원, 레몬에이드 5,500원, 치즈케이크 6,000원
- 메뉴를 누르면 주문 목록에 담기고, 아래에 합계 금액이 보이게
- 휴대폰 화면에서도 보기 좋게
```

줄바꿈은 `Shift+Enter`로 넣습니다.

## 원하는 것을 말하는 네 가지
1. **무엇을** — 만들 것 (메뉴 페이지, index.html)
2. **내용** — 나만 아는 정보 (가게 이름, 메뉴, 가격)
3. **동작** — 눌렀을 때 일어날 일 (주문 목록, 합계)
4. **확인 기준** — 다 됐는지 볼 방법 (휴대폰 화면, 합계가 맞는지)

## 결과 확인
`index.html`을 브라우저로 열고(파일 더블클릭) 메뉴를 눌러 합계가 맞는지 직접 확인합니다.

근거: [best-practices](https://code.claude.com/docs/en/best-practices), [how-claude-code-works#its-a-conversation](https://code.claude.com/docs/en/how-claude-code-works)
