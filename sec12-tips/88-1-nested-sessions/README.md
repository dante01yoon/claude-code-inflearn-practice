# 섹션 12 · 88-1강 세션 분할 — 큰일 하나를 클로드가 나눠 맡기게 하기

## 이번 수업에서 할 것
- Claude 데스크톱 앱 **v2.42304.0 (2026-10-15, Claude Code 2.1.299 포함)** 에 들어온 **세션 분할(nested sessions)** 을 써 본다. 로컬·SSH 세션에서 클로드가 일의 일부를 별도 세션으로 시작하고, 그 세션은 사이드바에서 원래 세션 아래에 붙어 일한 뒤 결과를 원래 세션에 보고한다.
- 같은 버전의 **환경 저장(Save as environment)** 으로 세션을 시작한 곳을 저장한다.
- 덤: Claude Code 2.1.299의 **쉬는 동안 자동 압축**(터미널).

공식 변경 기록: [Claude 데스크톱 changelog](https://claude.com/docs/cowork/changelog) · [Claude Code changelog](https://code.claude.com/docs/en/changelog)

## 준비
- Claude 데스크톱 앱(Code 탭) 2.42304.0 이상. 세션 분할·환경 저장은 아직 써드파티 배포판(Bedrock·Vertex 등)에는 없다.
- 빈 폴더 하나에 [`solution/data/`](solution/data/)의 세계은행 데이터 3개를 `data/`로 넣는다. 새로 받으려면 `data` 폴더 안에서 `sh fetch_data.sh`.

| 파일 | 내용 |
|---|---|
| `pop65.json` | 65세 이상 인구 비율 % (SP.POP.65UP.TO.ZS), 1990~2023 |
| `life-expectancy.json` | 기대수명 (SP.DYN.LE00.IN), 1990~2023 |
| `countries.json` | 국가 목록·지역·수도 위도/경도 (지역 묶음은 region이 "Aggregates") |

데이터 출처: 세계은행(World Bank) 공개 데이터 https://data.worldbank.org — 라이선스 **CC BY 4.0**.

## 입력한 것 (그대로, 한 번)
새로운 세션 창에서 위 폴더를 고르고 이렇게 보냈다.

```text
다음 주 발표용 마이크로사이트 하나 만들어 줘. 주제는 세계 고령화야. data 폴더 세계은행 데이터로 ① 나라별 65세 이상 인구 비율을 3D 지구본 위 기둥으로, ② 1990~2023 추세 대시보드, ③ 한국·일본·미국 고령화 정책 최신 동향 조사 브리핑(출처 링크 필수). 셋은 서로 상관없으니까 각각 별도 세션으로 나눠서 동시에 진행하고, 끝나면 index.html 하나로 합쳐 줘.
```

## 클로드가 나눈 방식
| 순서 | 원래 세션이 한 일 |
|---|---|
| 1 | 계획: data 폴더 구조 확인 → 3개 세션 동시 시작 → 세션 결과 확인 → index.html로 통합 → 브라우저에서 통합본 검증 |
| 2 | 하위 세션 3개 시작. 같은 폴더를 함께 쓰므로 **각자 자기 폴더에만** 쓰게 함 |
| 3 | 하위 세션이 끝날 때마다 보고를 받고(Received 3 messages), 결과를 확인 |
| 4 | 루트 `index.html`로 세 섹션을 합치고, 로컬 서버로 띄워 브라우저에서 확인 |

| 하위 세션 | 폴더 | 결과 |
|---|---|---|
| 3D 지구본: 국가별 65세+ 인구 비율 기둥 | `globe/` | 2023년 기준 기둥, 1990~2023 연도 슬라이더·재생, 상위 10개국, 마우스로 회전 |
| 고령화 추세 대시보드 1990~2023 | `trends/` | 핵심 수치 카드, 7%·14%·20% 기준선이 있는 추세선(국가 선택·툴팁), 증가폭 상위 15개국, 지역·소득 그룹 비교, 기대수명 vs 65세 이상 비율 산점도 |
| 한·일·미 고령화 정책 최신 동향 브리핑 | `policy/` | 16개 항목(한국 6·일본 5·미국 5), 출처 25개, 조사 기준일 2026-10-17. 확인하지 못한 항목은 빼거나 표시 |

사이드바에서는 원래 세션 아래에 세 세션이 들여 써서 붙고, 각 하위 세션 맨 위에는 "Started by Claude from (원래 세션)"과 받은 과제(Task)가 보인다. 녹화한 실행에서는 엔터부터 끝까지 약 13분(하위 세션 작업 약 8분)이 걸렸다.

## 결과물 실행
[`solution/`](solution/)이 완성된 마이크로사이트다. 데이터를 `fetch`로 불러오므로 파일을 더블클릭하면 비어 보인다. 로컬 서버로 연다.

```sh
cd solution
python3 -m http.server 8000
# 브라우저에서 http://127.0.0.1:8000
```

지구본·차트 라이브러리와 글꼴은 CDN에서 받으므로 인터넷이 필요하다. 정책 브리핑의 출처 링크는 조사한 원문 그대로다(일부 정부 사이트는 자동 확인을 막아도 브라우저에서는 열린다).

## 환경 저장 메모
- 세션 맨 위 "Started on This computer · (폴더)" 옆의 **Save as environment** → New environment 창에서 이름·폴더·환경 변수(Environment variables)를 정하고 Create environment.
- 저장한 뒤에는 새 세션의 Environment 메뉴(Local · Cloud · Remote Control)에서 바로 고른다. 저장할 수 있는 곳: 폴더, SSH 호스트, 클라우드 환경, Remote Control 기기.
- 사이드바는 저장한 환경별로 묶이고, 저장한 환경이 없으면 폴더·저장소별로 묶인다.
- 환경 변수가 저장한 환경마다 따로 붙는 것은 v2.31226.0(2026-10-08)부터.
- 앱 설정 Settings > Claude Code에서 관련 없는 작업을 부탁했을 때 어떻게 할지(세션 분할 동작)를 고를 수 있다.

## 덤: 쉬는 동안 자동 압축 (Claude Code 2.1.299, 터미널)
20만 토큰이 넘는 대화를 약 54분 쓰지 않으면, 1시간 프롬프트 캐시가 끝나기 전에 미리 압축해 다음 메시지 때 전체를 다시 처리하지 않는다. 끄기: `settings.json`에 `"idleCompaction": false`, 2.1.302부터 `/config`의 Idle compaction 줄.
