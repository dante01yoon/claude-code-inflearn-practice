# PRD와 리서치 — 실제 데이터와 근거 카드

데이터: [서울시 공공자전거 실시간 대여정보 OA-15493](https://data.seoul.go.kr/dataList/OA-15493/A/1/datasetView.do) (서울특별시, 공공누리 제1유형). 내 인증키는 열린데이터광장 가입 → 인증키 신청. 키 없이 `sample` 키로 한 번에 5건까지 시험할 수 있어 수업은 sample로 했습니다(키 값은 화면 · 저장소에 두지 않기).

PRD 다섯 제목(목표 · 사용자 · 기능 F1… · 데이터 출처+라이선스 · 범위 밖)을 `npm run check`가 확인합니다. 실제 실행 1분 17초: 기능 F1~F7, "API에 갱신 시각이 없어 받은 시각을 기준 시각으로", "0대 대여소가 없으니 숫자를 지어내지 말고 '예시 상태'로".
리서치(`/collect-references`, researcher 에이전트, 2분 11초): 공개 페이지만 휴대폰 크기로 캡처, 보안 확인 화면은 우회하지 않고 뺌(따릉이 공식 2곳 · 런던 1곳), 캡처는 근거 카드(observed 본 것 · take 가져올/피할 점)로만. 쓸 수 있는 레퍼런스 5개 → research PASS.
