# PRD: 따릉이 대여소 현황 (공공데이터 데모)

## 목표
서울시 공공자전거 따릉이의 대여소별 남은 자전거 수를 휴대폰에서 한눈에 보는 화면을 만든다.
공식 앱을 대체하지 않는 학습용 데모이며, 서울시 공개 데이터만 사용한다.

## 사용자
- 출근길에 가까운 대여소에 자전거가 남아 있는지 빠르게 확인하려는 따릉이 이용자
- 휴대폰 세로 화면(390×844) 기준

## 기능
- F0 지도: 실제 위치에 대여소 핀을 찍고, 핀에 남은 자전거 수를 보여 준다. 0대·1~2대는 색과 모양으로 구분한다.
- F1 대여소 목록: 지도 아래 바텀시트로 대여소 이름, 남은 자전거 수, 거치대 수를 보여 준다. 자전거가 0대인 대여소는 눈에 띄게 표시한다.
- F2 대여소 상세: 목록에서 고른 대여소의 남은 자전거 수, 거치대 수, 위치(위도·경도)를 보여 준다.
- F3 상태 화면: 데이터가 없을 때(빈 상태)와 불러오기에 실패했을 때(에러 상태)를 안내하고 다시 시도할 수 있게 한다.

## 데이터 출처
- 서울시 공공자전거 따릉이 실시간 대여정보 (서울 열린데이터광장 OA-15493), 제공 서울특별시
- 라이선스: 공공누리 제1유형(출처표시). 화면 하단에 출처를 표시한다.
- 데모 데이터: `data/stations.json` — 실제 API로 받은 망원·합정·서교 일대 대여소 17곳 스냅샷(fetchedAt 기록)
- 지도: OpenStreetMap 데이터(ODbL)로 직접 그린 바탕 `data/map-base@2x.png`. 지도에 "© OpenStreetMap" 표시

## 범위 밖
- 길찾기, 대여·결제, 로그인, 내 위치(데모에 실제 위치 없음 — 거리 표시 안 함)
- 실시간 자동 새로고침(데모는 스냅샷 데이터)
