# 따릉이 대여소 현황 앱 PRD

> 데이터 스냅샷: `data/stations.json` (서울 열린데이터광장 sample 키, 대여소 5곳, 받은 시각 2026-10-20 12:39 KST = 03:39 UTC)

## 목표
따릉이 이용자가 대여소에 가기 전에 **지금 자전거를 빌릴 수 있는지, 반납할 자리가 있는지** 한눈에 알게 한다.

- 대여소별 남은 자전거 수와 거치대 수를 숫자로 보여 준다. 색이나 아이콘만으로 상태를 전하지 않는다.
- 데이터가 언제 기준인지 항상 보여 준다. 실시간 API이지만 응답에 갱신 시각이 없으므로 앱이 받은 시각을 기준 시각으로 쓴다.
- 데이터를 못 받거나 오래됐을 때 이용자가 잘못된 숫자를 믿지 않게 한다.

## 사용자
- **빌리려는 사람**: 지하철역 출구 근처에서 자전거를 빌리려 한다. 가까운 대여소 중 자전거가 남은 곳을 찾는다.
- **반납하려는 사람**: 목적지 근처에서 반납할 빈 거치대가 있는 대여소를 찾는다.

공통: 걷거나 이동 중에 한 손으로 휴대폰을 보며, 몇 초 안에 판단한다.

## 기능
| ID | 기능 | 쓰는 필드 | 설명 |
|---|---|---|---|
| F1 | 대여소 목록 | `stationName`, `parkingBikeTotCnt`, `rackTotCnt` | 대여소마다 이름, 남은 자전거 수, 거치대 수를 보여 준다. |
| F2 | 대여 가능 상태 표시 | `parkingBikeTotCnt`, `shared` | 남은 자전거 0대 / 적음 / 여유를 숫자와 글로 함께 표시한다. 기준값은 디자인 시스템 단계에서 정한다. |
| F3 | 반납 가능 추정 | `rackTotCnt`, `parkingBikeTotCnt` | 빈 거치대를 `rackTotCnt − parkingBikeTotCnt`로 추정해 보여 준다. API가 주는 값이 아니라 추정임을 밝힌다. 0 이하이면 "빈 거치대 없음"으로 표시한다. |
| F4 | 대여소 상세 | 전체 필드 | 이름, 자전거 수, 거치대 수, 거치율(`shared`%), 위치(위도·경도)와 지도 앱으로 길찾기 연결. |
| F5 | 기준 시각과 새로고침 | `source.fetchedAt` | 화면 위에 "○시 ○분 기준"을 한국 시간(KST, UTC+9)으로 보여 주고, 당겨서 새로고침한다. 일정 시간이 지나면 오래된 데이터라고 알린다. |
| F6 | 검색 | `stationName` | 대여소 이름·번호(예: "102", "합정역")로 찾는다. |
| F7 | 상태 화면 | — | 불러오는 중, 불러오기 실패(다시 시도), 검색 결과 없음, 오래된 데이터를 각각 정의한다. |

### 스냅샷의 실제 값 (디자인에 쓸 데이터)
| 대여소 | 자전거 | 거치대 | 거치율 |
|---|---|---|---|
| 102. 망원역 1번출구 앞 | 5 | 15 | 33% |
| 103. 망원역 2번출구 앞 | 8 | 14 | 57% |
| 104. 합정역 1번출구 앞 | 4 | 13 | 31% |
| 105. 합정역 5번출구 앞 | 1 | 5 | 20% |
| 106. 합정역 7번출구 앞 | 7 | 12 | 58% |

이 스냅샷에는 자전거 0대 대여소와 거치율 100% 이상 대여소가 없다. 디자인 단계에서 이런 상태를 보여 줘야 하면 숫자를 지어내지 말고, API를 다시 받아 실제 사례를 찾거나 상태 화면에 "예시 상태"라고 표시한다.

### 데이터 특성과 제약
- 숫자 필드가 모두 문자열로 온다(`"15"`). 앱에서 숫자로 바꾼다. `stations.json`에는 바꾼 값을 저장했다.
- `shared`는 `parkingBikeTotCnt ÷ rackTotCnt × 100`을 반올림한 값으로 보인다(스냅샷 5곳 모두 일치).
- 응답에 갱신 시각 필드가 없다 → F5의 기준 시각은 받은 시각이다.
- 대여소 주소·운영 상태 필드는 없다. 이름의 출구 번호가 위치 단서다.

## 데이터 출처
- **데이터셋**: 서울시 공공자전거 실시간 대여정보 (서울 열린데이터광장 OA-15493)
- **제공**: 서울특별시
- **페이지**: https://data.seoul.go.kr/dataList/OA-15493/A/1/datasetView.do
- **호출**: `http://openapi.seoul.go.kr:8088/sample/json/bikeList/1/5/` (응답 코드 INFO-000)
- **라이선스**: 공공누리 제1유형(출처표시) — 앱 화면(정보·설정 등)에 "서울특별시, 서울 열린데이터광장" 출처를 표시한다.
- **키**: 지금은 공개 `sample` 키(한 번에 최대 5건)로 받았다. 실제 서비스는 열린데이터광장에서 인증키를 발급받아야 전체 대여소를 받을 수 있다.
