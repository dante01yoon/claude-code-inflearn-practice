# 📏 하네스 있음 vs 없음 — 같은 부탁 비교

같은 PRD · 모델 · 부탁 문장("화면은 3~4개 정도면 돼"), A = PRD+데이터만 있는 빈 폴더, B = 하네스 폴더(`/design-flow`). 절차 `experiment/PROTOCOL.md`, 입력 `run-*/prompt*.txt`.
**피그마에 다시 그리는 실험 자체(두 번 합쳐 20분 넘게 · 약 9달러)는 수업에서 다시 돌리지 않았고**, 남겨 둔 노드 파일과 세션 기록을 같은 스크립트로 다시 쟀습니다.

`npm run compare`: 색 13→7, 글자 크기 13→4, 간격 15→6, 모서리 6→2, 변수 미연결 색 100%→0, 대비 미달 24→0, 터치 44 미만 3→0, 기본 레이어 이름 10→0, 높이 다른 컴포넌트 0→1(B 불리), 빠진 상태 1→0 / 시간 3.1→17.9분, 비용 $1.41→$7.86, 블라인드 비평 11→12/20. `session-stats.mjs`로 로그에서 다시 계산한 시간 · 비용도 기록과 같음.
클로드 정리(`experiment/RESULTS.md`, 2분 49초)가 짚은 불리한 점: 시간 · 비용 5~6배, 하네스 안 비평 17/20 vs 독립 비평 12/20(자기 평가 후함), A의 터치 미달 3건은 이름 때문에 걸린 오탐, A 대비 미달 24건 중 11건은 4.18~4.35, B는 실행 도중 하네스 수정 · 운영자 대리 승인 · 노드 내보내기 설정이 절차와 다름(`ONLY_SCREEN_FRAMES=true`, 로그로 확인).
세션 로그는 개인 환경 정보가 들어 있어 저장소에는 result 이벤트(시간 · 턴 · 비용 · 토큰)만 남겼습니다. `session-stats.mjs`는 그대로 돌아갑니다.
