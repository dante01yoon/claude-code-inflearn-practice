# seoul-crowd

## 목표
서울시 주요 장소의 실시간 인구 데이터로 지금 얼마나 붐비는지, 앞으로 몇 시간 동안 어떻게 바뀔지를 한눈에 보여 준다. 화면은 2개(장소 목록, 장소 상세)다.

## 사용자
- 서울 도심(광화문, 명동 등)에 가려는 시민과 관광객. 출발 전에 붐비는 정도를 확인하고 방문 시간을 정하려 한다.
- 휴대폰에서 짧게 확인한다. 숫자보다 혼잡 단계(여유·보통·약간 붐빔·붐빔)를 먼저 읽는다.

## 기능
- F1: 장소 목록 — 서울시 주요 121장소를 이름으로 검색하고, 장소마다 현재 혼잡 단계와 기준 시각을 보여 준다.
- F2: 장소 상세 — 현재 혼잡 단계, 안내 문구(`AREA_CONGEST_MSG`), 추정 인구 범위(`AREA_PPLTN_MIN`~`AREA_PPLTN_MAX`), 기준 시각(`PPLTN_TIME`)을 보여 준다.
- F3: 혼잡 예측 — 장소 상세에서 앞으로 12시간의 예측 혼잡 단계와 인구 범위(`FCST_PPLTN`)를 시간대별로 보여 준다.
- F4: 방문자 구성 — 장소 상세에서 성별 비율, 연령대 비율(`PPLTN_RATE_0`~`70`), 거주·비거주 비율을 보여 준다.
- F5: 데이터 상태 — 불러오는 중, 오류(API 실패), 데이터 없음(인증 범위 밖 장소), 예측 미제공(`FCST_YN`=N) 상태를 보여 주고 출처를 표시한다.

## 데이터 출처
- 제공처: 서울특별시, 서울 열린데이터광장
- 데이터셋: 서울시 실시간 인구데이터 (OA-21778) — https://data.seoul.go.kr/dataList/OA-21778/S/1/datasetView.do
- API: `http://openapi.seoul.go.kr:8088/{KEY}/json/citydata_ppltn/1/5/{장소명 또는 장소코드}` — 한 번에 1개 장소만 호출된다.
- 인증키: `sample`. sample 키로는 121장소 중 **광화문·덕수궁(POI009)만** 조회된다. 나머지 장소는 인증키 발급이 필요하다.
- 장소 목록: 같은 데이터셋 페이지의 「서울시 주요 121장소명 목록(코드포함).xlsx」.
- 라이선스: 공공누리 제1유형(출처표시, 상업적 이용 및 변경 가능). 저작권자 서울특별시. 화면에 "자료: 서울특별시 서울 열린데이터광장"을 표시한다.
- 데이터 한계: 단기체류 외국인(90일 이하)은 추정에서 제외된다(데이터셋 안내).
- 근거 스냅숏: `data/sample-ppltn.json` (sample 키로 2026-10-20에 받은 광화문·덕수궁 실제 응답).
- 디자인에 쓰는 숫자·문구는 이 실제 응답에서만 가져온다. 다른 장소의 혼잡 단계·인구는 지어내지 않고, 목록에서는 이름만 보이고 "데이터 없음" 상태로 그린다.

## 범위 밖
- 회원가입·로그인, 즐겨찾기 동기화, 푸시 알림
- 지도 화면, 길찾기, 교통·날씨·행사 등 실시간 도시데이터의 다른 항목
- 인증키 발급과 121장소 전체 실시간 조회(sample 키 범위 밖)
- 과거 데이터 조회와 통계 분석
