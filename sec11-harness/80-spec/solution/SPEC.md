# 스펙: 환승역 노선별 승하차

## 목표
`subway.html`에서 환승역을 고르면 **노선마다 하루 평균 몇 명이 타고 내리는지**와 그 비중을 보여 준다. 묻는 것은 「이 환승역에서 어느 노선 이용이 많은가」 하나다.

## 범위
- 넣는 곳: `subway.html` 답 카드(`#answer`)의 노선 칩(`renderLines`) 아래에 「노선별 승하차」 칸 하나.
- 데이터: 앱 기본 데이터인 9월 승하차 CSV(`SUBWAY_CSV`). 새 데이터나 API 호출은 없다.
- 하지 않는 것: 시간 슬라이더 연동(값은 하루 합계 고정), 3D 기둥을 노선별로 나누기, `index.html`·새 페이지, 개찰구 안 환승 인원 추정.

## 노선 묶기
CSV `호선명`은 운영 기관 기준이라 승객이 아는 노선과 다르다. 읽을 때 아래 규칙으로 **승객이 아는 노선**으로 묶는다(원본 CSV와 `toSubwayRows` 결과는 그대로 둔다).

| CSV 호선명 | 묶은 노선 |
|---|---|
| 경부선, 경인선, 장항선 | 1호선 |
| 경원선 — 서빙고·옥수·응봉·한남·이촌(국립중앙박물관)·왕십리(성동구청)·청량리(서울시립대입구) | 경의중앙선 |
| 경원선 — 그 밖의 역 | 1호선 |
| 경의선, 중앙선 | 경의중앙선 |
| 일산선 | 3호선 |
| 과천선, 안산선 | 4호선 |
| 9호선2~3단계 | 9호선 |
| 분당선, 수인선 | 수인분당선 |
| 공항철도 1호선 | 공항철도 |
| 나머지(1~8호선, 9호선, 경강선, 경춘선, 서해선, 신림선, 우이신설선) | 그대로 |

- 경원선을 역으로 나누는 목록은 상수(예: `GYEONGUI_JUNGANG_ON_GYEONGWON`)로 둔다.
- 같은 묶은 노선에 든 행은 시간대별로 더한다(예: 서울역 1호선 + 경부선 → 1호선).
- 묶은 뒤 노선이 2개 이상인 역만 환승역으로 본다. 9월 CSV 기준 **76곳**(합친 행이 노선 2개 이상인 77곳 중 지축(3호선+일산선)은 3호선 하나가 되어 빠진다).
- 노선이 하나뿐인 역에서는 칸을 숨긴다.

## 노선 칩도 묶은 노선으로
막대를 누르면 그 노선 칩을 고르므로, 칩과 막대가 같은 기준이어야 한다.

- 답 카드의 노선 칩(`renderLines`)과 `selected.line`, `selectedRow()`가 쓰는 노선별 행(`entry.byLine`)을 **묶은 노선 기준**으로 바꾼다. 예: 서울역 칩은 「노선 합산 · 1호선 · 4호선 · 경의중앙선 · 공항철도」.
- 묶은 노선이 하나뿐인 역(지축)은 칩을 보이지 않는다(지금은 3호선·일산선 칩이 보인다).
- 검색 결과·TOP 5·두 역 비교·지도 툴팁에 보이는 노선 이름(`entry.lines`)은 이번 범위에서 바꾸지 않는다.

## 화면
제목 「노선별 승하차 · 하루 평균」. 노선마다 한 줄, 왼쪽에 노선 이름, 그 오른쪽에 **승차**·**하차** 두 열을 나란히 둔다.

```
노선별 승하차 · 하루 평균
              승차                       하차
6호선     ███████  18,443명 47%     ███████  17,909명 46%
5호선     █████    13,752명 35%     █████    14,063명 36%
경의중앙선 ██        4,151명 11%     █         3,321명  8%
공항철도   █         3,167명  8%     ██        4,041명 10%
개찰구를 드나든 인원만 셉니다. 개찰구 안에서 갈아탄 인원은 빠지고, 코레일 역은 여러 노선이 개찰구를 함께 써서 한 노선에 섞여 있을 수 있습니다. · 2026년 9월
```

- 값: 하루 평균 = 9월 합계 ÷ 일수(`days`). 다른 답 카드 숫자와 같은 반올림. 숫자는 `fmt`(`toLocaleString("ko-KR")`)로 천 단위 쉼표.
- 비율: 승차는 그 역 승차 합 대비, 하차는 하차 합 대비. 표기는 기존 `pct`(반올림해 0%가 되는 작은 값은 「1% 미만」).
- 막대 길이: 그 역 안의 모든 막대(승차·하차 모두)가 같은 눈금 — 가장 큰 값이 꽉 찬다. 그래서 승차와 하차 길이도 서로 비교된다.
- 순서: 승차+하차 합계가 많은 노선이 위. 같으면 노선 이름순.
- 작은 값: 숨기거나 「기타」로 묶지 않고 그대로 보인다(김포공항 경의중앙선: 9월 승차 2명 → 「0명 · 1% 미만」).
- 색: 막대는 **서울 지하철 공식 노선색**. 노선마다 CSS 변수(`--line-1`, `--line-2`, …, `--line-gyeongui`처럼)로 정의하고, 값은 공식 자료로 하나씩 확인한 뒤 넣는다(짐작 금지). 확인이 필요한 노선: 1~9호선, 경의중앙선, 공항철도, 수인분당선, 우이신설선, 신림선, 서해선, 경춘선, 경강선. 승차·하차는 같은 노선색에서 진하기(예: 하차는 옅게)로 구분하고, 열 머리글로도 적는다. `--series-on`/`--series-off`와는 따로 둔다. 노선 칩에도 같은 노선색을 쓴다(점이나 테두리).
- 누르기: 노선 줄을 누르면 그 노선 칩을 고른 것과 같다(`selected.line = 그 노선` → `renderLines()` → `render()`). 고른 노선 줄은 강조하고 나머지는 흐리게. 다시 누르거나 「노선 합산」 칩을 누르면 해제. 줄은 `button`이고 `aria-pressed`와 `aria-label`(예: 「6호선 승차 18,443명 47%, 하차 17,909명 46%, 6호선만 보기」)을 단다.
- 안내 문구: 칸 아래 작은 글씨 한 줄(위 예시). 출처 표시(서울특별시, 공공누리 제1유형)는 기존 것을 유지한다.
- 시간 슬라이더·시간 창을 바꿔도 이 칸은 다시 그리지 않는다(역이나 고른 노선이 바뀔 때만).

## 코드
### `transfer-lines.mjs` (새 모듈, 브라우저·Node 공용)
- `passengerLine(row)` → 묶은 노선 이름. 위 표를 따른다(경원선은 `row.STTN`으로 판단).
- `groupByLine(rows)` → 같은 역의 CSV 행들을 묶은 노선별 행으로. 행 모양은 API 행과 같다(`SBWY_ROUT_LN_NM` = 묶은 노선, `HR_*` 합계). 기존 `byLine`을 이것으로 만든다.
- `lineShares(lineRows, days)` → `[{ line, on, off, onShare, offShare }]`(하루 평균, 합계 많은 순). 필드 접근은 `stats.mjs`의 `count`·`total`을 쓰고 키 문자열을 직접 만들지 않는다.
- `LINE_COLOR_VARS`: 묶은 노선 → CSS 변수 이름.

### `subway.html`
- `entries`를 만들 때(`mergeStations` 부분) `byLine`을 `groupByLine` 결과로, 칩용 노선 목록을 묶은 노선으로.
- `renderLines`는 묶은 노선이 2개 이상일 때만 칩을 그린다.
- `renderTransfer()`(새 함수)가 칸을 그리고, 역 선택·칩 선택 때 부른다.
- 노선색 CSS 변수를 `:root`에 추가.

### `tests/transfer-lines.test.mjs` (9월 CSV 실제 값)
- `passengerLine`: 표의 각 줄(특히 경원선 창동 → 1호선, 옥수 → 경의중앙선, 분당선·수인선 → 수인분당선).
- 환승역 수 76, 지축은 노선 1개.
- 서울역 묶은 노선 4개, 9월 합계 1호선 승차 2,784,060·하차 2,487,687(1호선 + 경부선), 공항철도 승차 455,766.
- 공덕: 6호선이 1위, 노선 4개, 승차 비율 합 = 1.
- 김포공항: 노선 5개, 경의중앙선 승차 2·하차 0도 빠지지 않음.
- 청량리: 1호선 승차 727,908, 경의중앙선 승차 545,000(경원선 → 경의중앙선).
- 인천: 1호선·수인분당선 2개.

## 문서
- `CLAUDE.md` 구조에 `transfer-lines.mjs`와 답 카드의 「노선별 승하차」, 노선 칩이 묶은 노선 기준이라는 점, 노선색 CSS 변수를 한 줄씩 추가한다.

## 단계
한 단계씩 만들고, 단계마다 `npm test` 통과 + `npm start`(http://127.0.0.1:8000/subway.html)에서 「화면 확인」을 본 뒤 커밋한다. 앞 단계가 끝나야 다음 단계로 간다.

### 1단계 — 노선 묶기와 칩
- 할 일: `transfer-lines.mjs`의 `passengerLine`·`groupByLine`, `subway.html`의 `byLine`·칩 목록을 묶은 노선으로, 묶은 노선이 하나면 칩 숨김. 테스트: `passengerLine` 표, 환승역 76곳, 지축 1개, 서울역·청량리·인천 노선과 9월 합계.
- 화면 확인:
  - 서울역 칩이 「노선 합산 · 1호선 · 4호선 · 경의중앙선 · 공항철도」(경부선 칩 없음).
  - 서울역 「1호선」 칩을 누르면 답 카드 숫자가 1호선 + 경부선을 더한 값이 된다(바꾸기 전 1호선 칩 값보다 크다).
  - 청량리 칩이 「1호선 · 경의중앙선」, 인천 칩이 「1호선 · 수인분당선」.
  - 지축은 칩이 없다. 검색 결과·TOP 5의 노선 이름은 그대로다(「1호선·경부선…」).

### 2단계 — 칸과 숫자(막대 없이)
- 할 일: `lineShares`, `renderTransfer()`로 칸 추가 — 제목, 승차·하차 열 머리글, 노선마다 하루 평균 인원과 비율(`fmt`, `pct`), 합계 많은 순. 역을 고를 때 그린다. 테스트: 공덕 순서·비율 합 1, 김포공항 경의중앙선 포함.
- 화면 확인:
  - 공덕이 위 「화면」 예시 숫자와 같다(6호선 18,443명 47% / 17,909명 46% … 공항철도 맨 아래).
  - 김포공항에 경의중앙선 줄이 「0명 · 1% 미만」으로 보인다.
  - 단일 노선 역(예: 강남)과 지축에서는 칸이 없다. 다른 역으로 바꾸면 칸 내용이 바뀐다.
  - 모든 숫자에 쉼표.

### 3단계 — 막대(공통 눈금)
- 할 일: 숫자 옆에 막대. 역 안의 승차·하차 막대 모두 가장 큰 값 기준 하나의 눈금. 색은 아직 한 가지 중립색.
- 화면 확인:
  - 공덕에서 가장 큰 값(6호선 승차)만 막대가 꽉 차고, 6호선 하차 막대는 그보다 조금 짧다.
  - 김포공항: 5호선 승차 막대가 하차보다 길고, 9호선은 반대. 경의중앙선 막대는 거의 보이지 않는다.
  - 좁은 화면(창을 줄였을 때)에서도 숫자가 막대와 겹치지 않는다.

### 4단계 — 공식 노선색
- 할 일: 확인한 공식 노선색을 `:root` CSS 변수로(출처를 주석에), `LINE_COLOR_VARS`, 막대에 노선색(하차는 옅게), 노선 칩에도 같은 색 표시.
- 화면 확인:
  - 서울역 1호선 막대가 `#0052A4`, 4호선·경의중앙선·공항철도가 공식 색. 하차 막대는 같은 색의 옅은 톤.
  - 칩의 색과 막대 색이 노선마다 같다.
  - 김포공항(노선 5개), 고속터미널·왕십리 등에서 색이 빠진 노선(기본색으로 보이는 막대)이 없다.

### 5단계 — 줄 누르기 연동
- 할 일: 노선 줄을 `button`으로, 누르면 `selected.line` → `renderLines()`·`render()`, 고른 줄 강조·나머지 흐리게, `aria-pressed`·`aria-label`. 다시 누르거나 「노선 합산」 칩이면 해제.
- 화면 확인:
  - 공덕 「6호선」 줄을 누르면 6호선 칩이 눌린 상태가 되고 답 카드 차트·숫자가 6호선만으로 바뀐다. 6호선 줄만 진하다.
  - 같은 줄을 다시 누르거나 「노선 합산」 칩을 누르면 원래대로.
  - 칩으로 노선을 골라도 칸의 강조가 따라온다.
  - 키보드 Tab으로 줄에 가서 Enter·Space로 똑같이 동작한다.

### 6단계 — 안내 문구와 마무리
- 할 일: 칸 아래 안내 문구 한 줄, 시간 슬라이더·시간 창 변경 때 칸을 다시 그리지 않게 확인, `CLAUDE.md` 구조에 추가.
- 화면 확인:
  - 칸 아래 「개찰구를 드나든 인원만 셉니다. … · 2026년 9월」이 작은 글씨로 보이고, 출처 표시는 그대로다.
  - 시간 슬라이더를 움직이거나 재생해도 칸의 숫자·막대가 바뀌지 않는다.
  - 아래 「완료 기준」을 처음부터 끝까지 한 번 확인한다.

## 완료 기준
- `npm test` 통과(새 테스트 포함, 기존 테스트 깨지지 않음).
- `npm start` 후 서울역·공덕·김포공항·청량리를 골라 칸이 보이고, 단일 노선 역과 지축에서는 숨겨진다.
- 노선 줄을 누르면 칩과 답 카드 차트가 그 노선으로 바뀐다.
- 모든 숫자에 천 단위 쉼표, 막대 색이 공식 노선색.
