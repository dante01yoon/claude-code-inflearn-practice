# 섹션 10 · 76강 /loop로 잠깐 지켜보기 — 간격은 클로드가

## 이번 수업에서 할 것
- `/loop` = 잠깐 옆에서 지켜보기(열어 둔 세션 안에서만). 루틴(알람 예약, 클라우드)과 비교
- 쓰는 법 세 가지: `/loop 5m 부탁`(고정 간격) · `/loop 부탁`(간격은 클로드가 1분~1시간에서 매번 고름) · `/loop`(부탁 없이 = 기본 유지 부탁 또는 `loop.md`)
- 멈추기: 기다리는 동안 `Esc`, 또는 끝 조건을 부탁에 적어 클로드가 스스로 멈추게. 반복 작업은 7일 뒤 만료

## 입력한 것 그대로
```text
claude --permission-mode auto
/loop 광화문·덕수궁 실시간 혼잡도가 다음 갱신 때 바뀌는지 지켜보다가, 바뀌면 뭐가 바뀌었는지 알려 주고 멈춰
지금 예약된 작업 남아 있어?
```
